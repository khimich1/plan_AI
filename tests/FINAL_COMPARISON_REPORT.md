## 🔧 **ТЕХНИЧЕСКИЕ ИСПРАВЛЕНИЯ**

### **1. Группировка в смете:**

```python
# БЫЛО:
order_counter[(length, width)] += qty  # ❌ Без нагрузки

# СТАЛО:
order_counter[(length, width, load_code)] += qty  # ✅ С нагрузкой!
```

### **2. Форматирование ширины:**

```python
# БЫЛО:
f'{width_dm:.1f}'  # 6.65 → "6.7" ❌

# СТАЛО:
f'{width_dm:.2f}'.rstrip('0').rstrip('.')  # 6.65 → "6.65" ✅
```

### **3. Хранение нагрузок:**

```python
# Новая структура данных:
PLATE_LOAD_DETAILS[(length, width, load_code)] = qty

# Пример:
PLATE_LOAD_DETAILS[(7.3, 1.2, 8)] = 93   # ПБ 73-12-8п
PLATE_LOAD_DETAILS[(7.3, 1.2, 10)] = 4   # ПБ 73-12-10п (отдельно!)
```
