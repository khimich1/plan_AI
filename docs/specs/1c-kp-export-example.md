# Пример JSON выгрузки КП → 1С

> **Дата:** 17.09.2026  
> **Источник:** реальное КП **№22** (архив, 11.09.2026, АКТИВСТРОЙ ООО)  
> **Статус:** черновик для диалога с 1С (живой выгрузки ещё нет)  
> **Кодировка:** UTF-8  
> **ТЗ:** [`1c-integration-tz-v2.md`](./1c-integration-tz-v2.md) · чеклист [`1c-integration-meeting-checklist.md`](./1c-integration-meeting-checklist.md)

Запрос 1С (теги через `/`): Клиент, ИНН, КПП, Организация, Контрагент, КонтактноеЛицо, Валюта, ХозяйственнаяОперация, Налогообложение, ЦенаВключаетНДС, Статус, Комментарий, Менеджер, СуммаДокумента, Автор, Номенклатура, Характеристика, Количество, Цена, Сумма, СтавкаНДС, СуммаНДС, СуммаСНДС, ПроцентСкидки, СуммаСкидки, ВидЦены.

Сложные структуры — узлами. Шапка документа отдельно, табличная часть — массив `Товары`.

**Договорённость ТЗ v2:** в 1С уходит документ **«Счёт на оплату»**, КП остаётся в приложении. Теги те же; имя документа в JSON меняется после подтверждения 1С.

Чистый JSON: [`1c-kp-export-example.json`](./1c-kp-export-example.json).

## Откуда цифры

| Поле | Значение в КП 22 |
|---|---|
| Клиент | АКТИВСТРОЙ ООО, код `00-00000884`, ИНН `7604368921`, КПП `760401001` |
| GUID контрагента | нет (из xlsx-справочника только код) |
| Менеджер | Пургина Ольга Владимировна |
| Скидка | 13% на все строки |
| Позиции | 9 плит ПБ, GUID из `prays_plity` — все найдены |
| Доставка | 0 ₽, в JSON нет |
| Условия / комментарий | пустые |
| Статус у нас | `в архиве` |

Цена строки — `unit_price` до скидки (с НДС). `СуммаСНДС` = округление(`discounted_price` × `Количество`, 2). НДС в файле — **22/122** при `ЦенаВключаетНДС = true`.

В архиве КП хранится иначе: `total_amount` **357004.31**, `vat_amount` **78540.95** (= сумма × 0,22), `subtotal` **278463.36**. После округления строк до копеек `СуммаДокумента` в JSON = **357004.30** (−1 коп.). Формулу НДС нужно согласовать, иначе 1С получит **64377.82**, а в печатной форме КП — **78540.95**.

## Соответствие тегов данным приложения

| Тег 1С | Есть у нас | В КП 22 |
|---|---|---|
| Организация | константа PDF | `ООО «Комбинат ЖБК»` |
| Клиент / Контрагент.Наименование | `customer_name` | АКТИВСТРОЙ ООО |
| Контрагент.Код | `code_1c` | `00-00000884` |
| Контрагент.GUID | колонка есть, из xlsx почти пустая | `null` |
| ИНН / КПП | снимок КП | `7604368921` / `760401001` |
| КонтактноеЛицо | нет | `null` |
| Валюта | не храним | `RUB` |
| ХозяйственнаяОперация | не храним | константа, уточнить имя |
| Налогообложение | не храним | константа, НДС 22% |
| ЦенаВключаетНДС | цена позиции «уже с НДС» | `true` |
| Статус | «в архиве / в работе / в производстве…» | `в архиве` (нужен маппинг) |
| Комментарий | условия поставки, оплаты, срок | пусто |
| Менеджер / Автор | ФИО менеджера, без GUID физлица 1С | Пургина Ольга Владимировна |
| СуммаДокумента | `total_amount` | 357004.30 (в архиве 357004.31) |
| Номенклатура | марка / имя плиты | 9 плит ПБ |
| Номенклатура.GUID | резолвер GUID | все 9 найдены |
| Характеристика | не справочник 1С; у плит в БД есть `М400` | `null` (класс бетона в марке) |
| Количество | `qty` | да |
| Цена | `unit_price` до скидки, с НДС | да |
| ПроцентСкидки / СуммаСкидки | скидка на весь документ | 13% / 53345.48 |
| Сумма / СуммаНДС / СуммаСНДС | итоги КП | да; формулу НДС согласовать |
| ВидЦены | в прайсе 1С вид «Продажная» | константа `"Продажная"` |
| Номер / GUID документа 1С | нет | только наш `22` |

Доставка в КП — отдельная сумма («услуга по доставке грузов»), в базу НДС по плитам не входит. В КП 22 доставка 0 ₽.

## Вопросы к 1С по этому файлу

1. Документ в JSON — **КП** или **«Счёт на оплату»** (как в ТЗ v2)?
2. Имена констант: `ХозяйственнаяОперация`, `Налогообложение`, `Статус`, `ВидЦены` — как в вашей конфигурации?
3. НДС: 22/122 при цене с НДС (**64377.82** в этом файле) или × 0,22 как в наших печатных формах (**78540.95**)?
4. `Контрагент.GUID` обязателен, или достаточно `Код` + ИНН/КПП?
5. `Характеристика` — пусто, класс бетона строкой (`М400`), или отдельный справочник?
6. Доставку класть отдельной строкой?
7. Повторная загрузка: ищем документ по чему? (наш `НомерВПриложении` / GUID 1С / номер ЯР)
