# Инструкция по использованию расчета себестоимости плит

## Быстрый старт

### 1. Загрузка данных из Excel (один раз)

Перед первым использованием нужно загрузить данные из Excel файла:

```bash
python load_constants_from_excel.py
```

Это загрузит в БД:
- Объемы плит
- Стоимость бетона
- Стоимость армирования
- Стоимость изоформа
- Общую себестоимость (для проверки)

### 2. Расчет себестоимости

#### Вариант 1: Интерактивный режим

```bash
python calculate_plate_cost.py
```

Затем введите название плиты, например: `ПБ 17-12-6`

#### Вариант 2: Из Python кода

```python
from cost_calculation import calculate_plate_cost
import core.config_and_data as cfg

result = calculate_plate_cost("ПБ 17-12-6", cfg.PRICE_DB_PATH)

if result:
    print(f"Себестоимость: {result['total_cost']:,.2f} руб")
    print(f"Компоненты: {result['components']}")
```

## Формат названия плиты

Формат: `ПБ {длина_дм}-{ширина_дм}-{нагрузка}п`

Примеры:
- `ПБ 17-12-6` - длина 1.7 м, ширина 1.2 м, нагрузка 6п
- `ПБ 20-12-8` - длина 2.0 м, ширина 1.2 м, нагрузка 8п
- `ПБ 30-12-10` - длина 3.0 м, ширина 1.2 м, нагрузка 10п

## Структура результата

```python
{
    'plate_name': 'ПБ 17-12-6',
    'parameters': {
        'length_dm': 17,
        'length_m': 1.7,
        'width_dm': 12,
        'width_m': 1.2,
        'load_code': 6,
        'concrete_grade': 'М400'
    },
    'volume_m3': 0.2805,
    'components': {
        'concrete': 1708.91,      # стоимость бетона
        'reinforcement': 213.28,   # стоимость армирования
        'loops': 286.0,           # стоимость петель
        'izoform': 11.63          # стоимость изоформа
    },
    'total_cost': 2219.82,        # общая себестоимость
    'breakdown': {                # детальная разбивка
        'concrete': {...},
        'reinforcement': {...},
        'izoform_kg': 0.1224
    }
}
```

## Проверка точности

Программа автоматически сравнивает результат с данными из Excel и показывает разницу.

Если разница < 1% - ✅ Совпадает с Excel
Если разница < 5% - ⚠️ Небольшое расхождение
Если разница > 5% - ❌ Значительное расхождение

## Обновление данных

Если Excel файл обновлен, запустите снова:

```bash
python -m cost_calculation.load_from_excel
```

Это обновит все данные в БД.

## Примеры использования

### Пример 1: Простой расчет

```python
from cost_calculation import calculate_plate_cost
import core.config_and_data as cfg

result = calculate_plate_cost("ПБ 17-12-6", cfg.PRICE_DB_PATH)
print(f"Себестоимость: {result['total_cost']:,.2f} руб")
```

### Пример 2: Расчет для нескольких плит

```python
plates = ["ПБ 17-12-6", "ПБ 20-12-8", "ПБ 30-12-10"]

for plate_name in plates:
    result = calculate_plate_cost(plate_name, cfg.PRICE_DB_PATH)
    if result:
        print(f"{plate_name}: {result['total_cost']:,.2f} руб")
```

## Файлы

- `cost_calculation/load_from_excel.py` - загрузка данных из Excel
- `cost_calculation/examples/calculate_interactive.py` - интерактивная программа расчета
- `cost_calculation/calculation.py` - функции расчета
- `cost_calculation/db.py` - работа с БД констант

## База данных

Все данные хранятся в `pb.db` в следующих таблицах:
- `plate_volumes` - объемы плит
- `concrete_costs` - стоимость бетона
- `reinforcement_costs` - стоимость армирования
- `izoform_costs` - стоимость изоформа
- `excel_total_costs` - общая себестоимость из Excel (для проверки)
