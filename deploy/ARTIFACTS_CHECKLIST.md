# Артефакты вне Git (деплой «Шишов»)

См. также [`.gitignore`](../.gitignore). После `git clone` на сервере этих файлов и папок **не будет** — перенесите их вручную (scp, rsync, архив).

## Обязательно для полноценной работы

| Что | Куда на сервере | Примечание |
|-----|-----------------|------------|
| `pb.db` | корень репозитория | База цен; путь задаётся в [`core/db_config.py`](../core/db_config.py) |
| `plita.db` | корень репозитория | КП и плиты; при отсутствии может создаваться при работе |
| `банк знаний/` | корень репозитория | Прайс/данные; путь в [`bot/bot_config.py`](../bot/bot_config.py) |
| `BOT_TOKEN` | `bot/bot.env` или `.env` в корне | Не коммитить; см. [`bot/bot.env.example`](../bot/bot.env.example) |

## Опционально

| Что | Куда | Примечание |
|-----|------|------------|
| `Визуализация_Раскладки/` | корень | Уже сгенерированные файлы; каталог создаётся при старте бота |
| `*.db-shm`, `*.db-wal` | рядом с `.db` | Только если копируете «живую» БД — сначала остановите бота на источнике |
| `OPENAI_API_KEY` и др. | тот же env-файл | GPT/OCR и прочие переменные из плана деплоя |

## Локальная проверка перед копированием

Из корня проекта:

```bash
python scripts/smoke_check.py
```

## Один токен — один процесс

Не запускайте `run_bot.py` одновременно на ПК и на VPS с одним `BOT_TOKEN` (конфликт long polling).
