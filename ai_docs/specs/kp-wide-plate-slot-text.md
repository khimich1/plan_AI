## Assumptions I'm Making

1. **Подтверждено в идее 2026-10-26.** Пользователь — менеджер на шаге «Плиты». Продукт только `plates`. Один и тот же блок на сверке фото и на распознавании текста без фото.
2. **Подтверждено.** Список по умолчанию свёрнут, даже если широкая плита одна. Плашка — та же, что у старого блока: «▸ N позиций требуют внимания», по клику «▾» и панели. N считает широкие строки без нажатого «ОК». Ноль — карточки нет.
3. **Подтверждено.** «ОК» стоит в одной строке с «Подтвердить / Заменить / Исключить», сразу справа от «Исключить», по высоте этих переключателей. Это не широкая primary-полоса под полем. Поле «Заменить» по-прежнему под строкой радио.
4. **Подтверждено.** Текст без фото пишет список той же функцией, что фото. «ОК» и «Применить решения» не вызывают `wide-plates/resolve`. Сервер видит уже записанный текст позже.
5. **Подтверждено.** Открытая широкая строка держит «Готово, далее». Нажатый «ОК», в том числе «Подтвердить», отпускает. Флаг `wide_plates_resolved` после локальной записи шаг не держит. «Список верен» на сверке по-прежнему нужен сам по себе.
6. **Подтверждено.** Правила слота предыдущей спеки не меняются: липкое поле, две одинаковые марки, вставка выше, сброс при ширине ≤ 12 дм, пустая замена, низ идёт сверху вниз и стоп на первой ошибке, правка после «Подтвердить» снимает только «ОК».
7. **Принимаю, пока не поправят.** Смена активного фото снова сворачивает список. Раскрытие не переезжает на соседний снимок.
8. **Принимаю из предыдущей спеки, пока не поправят.** «ОК» «Подтвердить» сессионный. Полная перезагрузка черновика может снова открыть широкую строку, которую подтвердили как есть. «Заменить» и «Исключить» переживают перезагрузку, потому что широкой строки в тексте уже нет. Для текста без фото то же правило.
9. Суффикс нагрузки, verify OCR, гейты заводского реза и позиций без цены не меняем. Контракт `wide-plates/resolve` не меняем: его просто не зовут с этих кнопок.
10. Коммит агент не делает без явной просьбы.

→ Если пункты 7 или 8 неверны — править spec до плана.

## Decisions locked

| # | Тема | Решение |
|---|------|---------|
| D1 | Один блок | Фото и текст без фото показывают `WidePlateSlotSection`. Старый блок с решением по марке на этих экранах не монтируется |
| D2 | Плашка | В `actions` карточки. Подпись ровно `▸ {n} позиций требуют внимания` или `▾ {n} позиций требуют внимания`. Свёрнуто при первом показе. Свёрнутый абзац ровно: `Разверните блок, чтобы принять решение по каждой позиции, затем нажмите «Применить решения».` |
| D3 | Что считает N | Широкие строки текущего списка, у которых нет слота с `accepted`. Это то же множество, которое держит «Готово, далее» |
| D4 | Где «ОК» | Последний элемент flex-ряда радио этой панели. Ширина по надписи «ОК», не по ширине карточки. Под полем замены кнопки «ОК» нет |
| D5 | Где низ | «Применить решения» только внутри раскрытого списка. Свёрнутая плашка её не показывает |
| D6 | Текст без фото | Слоты лежат в `wideSlotsByPage` под ключом `text-review`. Это не id снимка. Текст списка — `batchReviewText` этой сверки. Перенос слота при правке — тот же `carryWideSlots` |
| D7 | Запись | «ОК» и низ зовут ту же локальную запись, что на фото. `routeWidePlateApply` для открытой сверки текста тоже `"local"` |
| D8 | Шаг | «Готово, далее» на тексте без фото смотрит на открытые слоты `text-review`, не на `wide_plates_resolved`. Подтверждённая как есть широкая строка шаг не держит |
| D9 | Чужой список | «ОК» на фото пишет только активную страницу. «ОК» на тексте пишет только текст этой сверки |
| D10 | Что не меняем | Контракт resolve, invalid width, unpriced, verify OCR, алгоритм переноса слота, липкое поле |

## Objective

**Проблема.** На фото плашка «N позиций требуют внимания» пропала: секция слотов всегда раскрыта, а «ОК» растянута на ширину карточки. На тексте без фото плашка жива, но решение приклеено к марке и уходит в `wide-plates/resolve`. Правка ложной строки снова снимает или переносит выбор. Флаг `wide_plates_resolved` после локального «Подтвердить» не отпускает «Готово, далее».

**Цель.** Менеджер на обоих входах видит свёрнутую плашку со счётом, раскрывает панели и закрывает каждую маленькой «ОК» в ряду радио. Запись одна и локальная. Шаг отпускается, когда ненажатых «ОК» не осталось.

**Пользователь:** менеджер, шаг «Плиты», сверка фото или распознавание текста без фото.

**Успех:** плашка свёрнута, пока её не нажали; «ОК» в ряду радио и не на всю ширину; текст без фото после «ОК» содержит результат решения и не шлёт `wide-plates/resolve`; «Подтвердить» не оставляет шаг закрытым из-за `wide_plates_resolved`.

### Сценарии

1. **Плашка свёрнута.** Одна широкая строка. Видны заголовок карточки и «▸ 1 позиций требуют внимания». Панели, поле замены и «Применить решения» не видны. Подпись: «Разверните блок, чтобы принять решение по каждой позиции, затем нажмите «Применить решения».»
2. **Раскрытие.** Клик по плашке показывает панель. «ОК» в том же ряду, что «Подтвердить», «Заменить», «Исключить», и стоит сразу после «Исключить». Кнопка не тянется на ширину карточки. «Заменить» показывает поле под рядом, не вместо «ОК».
3. **Счётчик.** Две открытые широкие строки. Плашка: «▸ 2 позиций требуют внимания». «ОК» на первой уменьшает счёт до 1 и убирает эту панель. Ноль открытых — карточки нет.
4. **Текст без фото, замена.** Нет снимков. В списке `ПБ 76-15-8 13`. Раскрыть, «Заменить», в поле две строки подсказки, «ОК». В тексте сверки эти две строки, `76-15-8` нет. Запроса `wide-plates/resolve` нет.
5. **Текст без фото, низ.** Три широкие строки, радио не трогали. «Применить решения» закрывает все три как «Подтвердить». Строки те же. `wide_plates_resolved` может остаться ложным. «Готово, далее» широкой плитой больше не держится. «Список верен», если сверка ещё не подтверждена, по-прежнему нужен сам по себе.
6. **Правка марки на тексте.** Две строки `ПБ 76-15-8 13`. Правка первой меняет только первый слот. «ОК» только на первой пишет замену первой и оставляет вторую карточку с её радио и полем.
7. **Липкое поле на тексте.** Слот `ПБ 76-15-8 13`, «Заменить», поле про 76 не трогали. В списке строка стала `ПБ 68-15-8 13`. «ОК» пишет `ПБ 76-12-8 13` и `ПБ 76-3.0-8 13`.
8. **Пустая замена.** «Заменить», поле пустое. «ОК» и низ не меняют текст, «ОК» не нажат, ошибка «Укажите заменяющие позиции.» В пачке низа уже записанные слоты остаются, слот с ошибкой и те, что ниже, в этот клик не пишутся.
9. **Фото не ломаем.** «ОК» на активном снимке не меняет соседний. Слоты фото остаются на id страницы, не на `text-review`. Смена снимка показывает список выбранного и снова свёрнутую плашку.
10. **Подтвердить и поправить.** «ОК» «Подтвердить» закрыл панель. Та же строка стала другой маркой шире 12 дм. Панель снова в счёте, радио и поле прежние, «ОК» снят.

## Code Style

Оболочка не заводит второй словарь решений. Счёт и гейт смотрят на одно и то же: широкая строка без `accepted`. «ОК» — сосед радио, не отдельная строка сетки карточки.

```tsx
const TEXT_REVIEW_SLOT_PAGE_ID = "text-review";

<div style={{ display: "flex", gap: "0.75rem", flexWrap: "wrap", alignItems: "center" }}>
  {radios}
  <Button type="button" variant="secondary" onClick={() => onAccept?.(slot.id)}>
    ОК
  </Button>
</div>
```

Кнопка в этом ряду не получает ширину карточки. Запись текста без фото идёт в `commitWideSlots` по слотам `wideSlotsByPage["text-review"]`. Поиск решения по `normalizeLineKey` на этом экране не используется.

## Testing Strategy

Уровень — unit на чистые функции и тесты секции и шага. Браузерный прогон этой спекой не требуется: свёрнутость, соседство «ОК» и радио, локальная запись и гейт шага видны из рендера и состояния слота.

| Тест | Что доказывает |
|------|----------------|
| Секция при открытых слотах | Плашка «▸ N позиций требуют внимания», панелей нет, пока плашку не нажали |
| Клик по плашке | Панель видна, «ОК» в родителе радио «Исключить», не под полем замены |
| «ОК» одной из двух | Счёт стал N−1, закрытой панели нет |
| `routeWidePlateApply` для сверки без фото | `"local"`, не `"resolve"` |
| Запись в текст без фото | `commitWideSlots` по ключу `text-review` пишет строки поля и не оставляет вторую карточку на той же строке |
| Гейт шага | Широкая строка без `accepted` блокирует. Все слоты `accepted` не блокируют, даже если `wide_plates_resolved` ложен |
| Пустая замена в пачке | Верх записан, отказавший открыт, нижние в этот вызов не записаны |
| Регрессия фото | Слот страницы не читается и не пишется как `text-review` |

Существующие тесты `flushThenResolveWidePlates` не переписывать: эти кнопки их больше не вызывают. Алгоритм `carryWideSlots` не менять и не дублировать. Покрытие всего репозитория не поднимаем.

## Boundaries

- **Always:** одна секция на фото и на текст; плашка свёрнута, пока её не нажали; «ОК» в ряду радио и не на ширину карточки; одна локальная запись для «ОК» и низа; гейт шага смотрит на слоты, не на `wide_plates_resolved`; пустую замену не записывать; прогнать команды из раздела Commands.
- **Ask first:** новый endpoint, правка контракта `wide-plates/resolve`, сохранение «ОК» «Подтвердить» после полной перезагрузки, правка invalid width / unpriced / verify OCR, коммит.
- **Never:** монтировать на этих экранах старый блок с ключом марки; звать resolve с «ОК» или низа; растягивать «ОК» на ширину карточки; раскрывать список, когда плита одна; писать секреты; удалять падающий тест без замены, которая ловит тот же разрыв.
