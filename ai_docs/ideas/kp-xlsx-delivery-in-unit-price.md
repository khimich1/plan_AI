# КП: Excel с доставкой в цене изделия

## Problem Statement

Как менеджеру из архива выгрузить второй Excel того же КП — без строки доставки, с той же суммой к оплате, где доставка (уже с НДС, без скидки) равномерно сидит в цене каждой штуки?

## Recommended Direction

Одна дополнительная кнопка в карточке архива, рядом с обычными PDF/XLSX. Сохранённое КП, плашка «Итого», производство и обычные файлы не трогаем.

В файле: строка «Услуга по доставке» исчезает; к цене каждой штуки **после скидки** добавляется доля доставки на штуку; копейки добиваются так, чтобы сумма строк = текущий итог к оплате. НДС в этом файле = сумма строк × 22% (и с доставки тоже — тариф рейса уже с НДС). Имя файла явное: `КП_{id}_с_доставкой_в_цене.xlsx`.

Для смешанного КП (плиты + сваи) — два котла: доставку плит только на штуки плит, свайную только на сваи.

Под таблицей — одна строка-пояснение: в стоимость изделий включена доставка N рейсов на сумму X, скидка на доставку не распространяется.

## Key Assumptions to Validate

- [x] Заказчику достаточно Excel; обычный PDF с отдельной доставкой его устраивает (PDF в этом режиме — не MVP)
- [x] Надбавка на штуку (не на тонну) — то, что просят
- [x] Цена доставки уже включает НДС 22%; во «вшитом» файле строка НДС считается со всей суммы
- [x] Скидка на доставку не распространяется
- [x] Обычное КП с отдельной строкой доставки тоже нужно — два файла рядом, не замена
- [ ] Разница в строке НДС между двумя файлами при том же итоге не пугает бухгалтерию заказчика — проверить на 1–2 реальных КП после выгрузки

## MVP Scope

- Кнопка в архиве (`OfferDetailsDrawer`)
- Генерация XLSX с надбавкой на штуку после скидки
- НДС со всей суммы строк (включая вшитую доставку)
- Копейки: сумма строк = итог к оплате
- Два котла для плит / свай
- Доставка 0 ₽: кнопка неактивна
- Карточка архива без изменений (доставка отдельной плашкой)

## Not Doing (and Why)

- **PDF в этом же режиме** — тот же расчёт, другой генератор; вернёмся, если заказчик начнёт просить именно PDF
- **Переписывать цены в КП** — сломает обычный документ, скидку и «В производство»
- **Менять НДС в обычном PDF/XLSX** — отдельная история: сейчас налог с доставки там не показан, хотя в тарифе он уже сидит
- **Переключатель вместо второй кнопки** — два требования заказчика живут рядом
- **Надбавка по весу** — выбрана штука
- **Визард / шаг результата** — точка входа только архив
