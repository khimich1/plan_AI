# ГСМ: один месяц, один комплект

Дата: 2026-08-26. Статус: **direction confirmed**. Спека:
[`../specs/gsm-month-close-kit.md`](../specs/gsm-month-close-kit.md).
Контекст: обзор флота
[`gsm-fleet-overview-ux`](gsm-fleet-overview-ux.md) (хвост `open_before`,
два календаря, zip ПЛ отдельно от отчёта) и отчёт
[`gsm-fuel-usage-report`](gsm-fuel-usage-report.md) (сводка + вложенные
бланки, строки только `confirmed`/`exported`). Live: после перегенерации
июля Tugella 952 / Monjaro бейдж «до периода незакрыто», путаница
«Отчёт за период» vs «Экспорт zip», разорванная цепочка бака Monjaro
(конец июля 27,59 л / 62 846 ≠ старт августа 18,09 л / 62 946).

## Problem Statement

How might we закрывать месяц ГСМ так, чтобы бухгалтер видел **какой**
месяц не выгружен, одним кликом получал сводку и бланки ПЛ по одним и
тем же дням (включая черновики) и не мог выгрузить следующий месяц, пока
предыдущий открыт или цепочка бака порвана?

## Recommended Direction

Один рабочий месяц на экране. Стрелки журнала и баннер хвоста ставят
фильтры «С/По» на **1-е … последнее число** этого месяца. Поля дат
остаются для редкого произвольного диапазона; следующая стрелка снова
схлопывает в календарный месяц.

Хвост: «Июль не выгружен: N ПЛ», не «до периода». Стоп **по машине**:
у кого открыт хвост или порвана цепь — эту машину нельзя генерировать
и нельзя класть в комплект **текущего** месяца; сосед без хвоста едет.
CTA по строке — перейти на хвост и собрать комплект этой машины.

**Генерация только по галочкам.** «Сгенерировать выбранные» при нуле
галок ничего не делает. Строка/журнал — явное действие по одной машине.

**Одна кнопка комплекта: «Отчёт за период»**, подпись мелко: «сводка и
путевые». Без галочек — все активные, но с хвостом/разрывом исключаются
из zip с текстом. Zip:

- `Отчет по использованию ГСМ <госномер>.xls` — строки = те же дни, что
  бланки, **включая бывший `draft`**;
- бланки `ПЛ ДД.ММ.ГГ.xls`.

После успеха дни → `exported`. Повтор — confirm «уже выгружалось».

Красная машина (`manual_intervention`) исключается из zip, на экране
даты. Жёлтые warnings — confirm, не стоп.

«Экспорт zip выбранных» с UI убрать. «Экспорт» в строке / баннер =
комплект **хвоста этой машины** + календарь на хвост.

После комплекта хвоста: если первая точка текущего месяца не стыкуется с
концом предыдущего (бак/одометр) — комплект текущего **нельзя**, кнопка
**«Пересчитать {месяц}»** (generate от последнего `exported`). Если стык
есть или текущего месяца ещё нет — не предлагать. Молча `_rechain`
старых км не делать.

Старт генерации по-прежнему с последнего `confirmed`/`exported`: август
не генерируют, пока июль не закрыт.

## Key Assumptions to Validate

- [ ] Сводка с только что закрытых `draft` годится к подписи (эталон мая
      848 был из уже закрытых дней).
- [ ] Повторный комплект уже «Выгружено» при пустых галочках ок при
      confirm.
- [ ] Бухгалтер закрывает календарный месяц; произвольный «С/По» —
      исключение.

## MVP Scope

- Журнал и обзор — один календарный месяц (стрелки синхронизируют
  фильтры).
- Текст хвоста с именем месяца; стоп generate/комплекта текущего **у
  этой машины** при открытом хвосте или разрыве цепи; bulk generate
  только с галочками.
- Отчёт: `draft` в том же наборе, что бланки; `exported`; красных
  исключить + назвать дни.
- Убрать с UI zip-только-ПЛ; ряд/баннер ведут на комплект хвоста.
- Детект разрыва цепи с предыдущим месяцем → стоп комплекта +
  «Пересчитать».

## Not Doing (and Why)

- Старт августа с july `draft` в обход exported — при hard stop не нужен.
- Автогенерация следующего месяца после комплекта — затрёт ручные правки.
- Подкрутка только литров (`_rechain`) — маршруты останутся от чужого
  старта.
- Месяц как папка 1С / отдельный режим перегенерации.
- Менять колонки бланка сводки / склейку дней.
- Удалять `POST /waybills/export` из API — только скрыть кнопку.
