# Карта маршрутов ГСМ (HTML + привязка адреса)

> Ideation session: 2026-08-11  
> Контекст: `ГСМ/пул_поездок.xlsx` (лист `routes_ab`), 4 машины завода.  
> Связанные: [`gsm-trip-pool.md`](./gsm-trip-pool.md)

## Problem Statement

Как из пула уникальных поездок получить личную карту маршрутов в браузере на ПК — все машины и каждая своим цветом, линии по дорогам — чтобы по адресу (например заправки) понять, к какому маршруту эта точка относится?

## Recommended Direction

Один offline/локальный HTML (`ГСМ/карта_маршрутов.html`), собираемый скриптом из `пул_поездок.xlsx`:

1. **Геокэш адресов** — один раз геокодируем уникальные точки из `routes_ab` → файл кэша (правка вручную при ошибках).
2. **Треки по дорогам** — для уникальных пар A→B строим геометрию через публичный роутер (OSRM или аналог), кэш треков на диск.
3. **Карта** — Leaflet (или аналог): слои/цвета по машинам, фильтр «все / одна машина», попап с A, B, км, частота.
4. **Привязка адреса** — поле ввода адреса → геокод → маркер → **ближайший трек** (машина, A→B, расстояние до линии). Порог «относится» (например 200–500 м); иначе «не найден».

«Относится к пути» в MVP = минимальное расстояние точки до геометрии маршрута, не привязка к конкретному дню/ПЛ.

Пользователь: только вы, ПК, браузер. Не модуль в «Шишов».

### Решения

- Формат: один HTML в `ГСМ/`.
- Успех MVP: 4 цвета + ввод адреса заправки → подсветка одного маршрута с подписью.

## Key Assumptions to Validate

- [ ] Геокод адресов из ПЛ даёт приемлемые координаты (выборочно 20 точек глазами)
- [ ] Роутер отрабатывает дедуплицированный набор A→B без ручного ада (квоты/таймауты)
- [ ] «Ближайший трек» для типовых заправок совпадает с ожидаемым маршрутом
- [ ] Один HTML с встроенными/рядом лежащими GeoJSON открывается локально в браузере

## MVP Scope

- Скрипт: `routes_ab` → геокэш → треки → `карта_маршрутов.html`
- Цвета по 4 машинам + переключатель видимости
- Поиск: адрес → ближайший маршрут
- Кэш геокода и треков на диске (повторный прогон без сети, где возможно)

## Not Doing (and Why)

- Мобильная геолокация «где я сейчас» — нужен ПК и сценарий «адрес заправки»
- Модуль в frontend «Шишов» — личное использование
- Привязка к дню/конкретному ПЛ — достаточно каталога маршрутов
- Ручная отрисовка в Яндекс «Мои карты» как основной путь — меньше автоматизации
- Идеальная точность каждого адреса без ручной правки кэша — кэш правим точечно

## Open Questions

Закрыты при реализации:
- Геокодер/роутер: Nominatim + публичный OSRM (+ Photon для поиска в HTML).
- Порог: не фиксировать — показывать топ-3 ближайших.
- MVP: только уникальные A→B (`routes_ab`); `rounds_aba` — out of scope.
