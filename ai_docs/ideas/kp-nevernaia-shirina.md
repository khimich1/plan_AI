# Неверная ширина в составе КП

_Дата: 2026-09-02 · Статус: направление подтверждено · Источник: предпросмотр КП с ПБ 29-8-8п / 32-8-8п / 36-8-8п_

## Problem Statement

Как не дать менеджеру уйти с предпросмотра КП с шириной, которую завод не режет, и за один шаг поставить заводскую ширину или снять позицию — без «оставить как есть» и без сюрприза в цене.

## Recommended Direction

Карточка-гейт под таблицей «Состав КП», по контракту `UnpricedPlatesInlineSection` / `commercial_plate_resolve`: список проблемных строк → выбор замены или исключение → «Применить». Пока не применено — расчёт и сохранение не идут.

Детектор не ищет «-8-» в тексте. Ширину берём уже разобранную (`parse_pb_width_to_m` / `width_m`) и проверяем миллиметры против таблицы резов завода. Запись `8`, `8,0`, `0.8`, `800` — одна и та же 800 мм.

Подсказки — два соседа по таблице (край снизу и край сверху). Одно правило на все значения вне диапазона: 800 → 7,2 и 8,6; 1000 → 9,2 и 10,2. Особой клички «10 → 10,8» нет.

Плиты шире 12 дм не трогаем: у них свой гейт с другим правилом (можно подтвердить как есть).

Правка карандашом в таблице + «Список верен» пересчитывает состав: если ширина попала в диапазон — ошибка снимается без карточки.

## Key Assumptions to Validate

- [x] Блокируем всё вне диапазонов, не только «8» — подтверждено 2026-09-02.
- [x] Замены — соседи по таблице для любого значения — подтверждено.
- [x] 0,3 м = 300 мм входит в 260–320 — не гейт.
- [x] Карандаш снимает ошибку после пересчёта — принято по умолчанию.
- [ ] Ежедневные марки `-10-` (1000 мм) менеджеры готовы каждый раз менять на 9,2 / 10,2. Если нет — клички выносим отдельно, не ломая гейт для 8 / 4 / 6 / 11.

## MVP Scope

Детекция по мм, блок wizard, карточка «заменить / исключить», перепись марки, подсветка строки, все способы записи ширины через текущий парсер. Каркас `commercial_plate_resolve`.

## Not Doing (and Why)

- **Тихая замена 8→8,6** — нужна явная ошибка и выбор.
- **«Оставить как есть»** — снова пропуск нерезабельной ширины.
- **Решение в ячейке таблицы** — дублирует гейт; карандаш уже есть.
- **Слияние с широкими >12 дм** — у них другое правило (confirm).
- **Раскладка / snap в `add_items`** — сначала не выпускаем кривую марку из КП.
- **Производство** — этот экран, не цех.
