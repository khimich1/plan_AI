# Идея: GSM — коридор бака по пулу маршрутов всего парка

Дата: 2026-08-26. Статус: **direction confirmed**. Спека:
[`../specs/gsm-fleet-pool-corridor.md`](../specs/gsm-fleet-pool-corridor.md).
Контекст: после july-reset якоря 30.06; красные дни июля Monjaro 01/02/16.07
и Tugella 952 27–28.07. Предшественник:
[`gsm-anchor-corridor-wash-qty`](gsm-anchor-corridor-wash-qty.md) (коридор
только **внутри группы typical станции** — дыра осталась).

## Problem Statement

How might we на якоре (мойка или заправка) выбирать маршрут так, чтобы бак
оставался в `[0 … объём]`, если такой километраж есть у **этой машины или
у любой другой** в парке — без выдуманных городов и без зажима остатка в 0?

Сейчас две разные дыры выглядят одинаково (`left corridor` / красный день):

1. **Короткий есть, солвер не видит.** Monjaro 01.07: бак 7,21 л, только
   мойка (Ленина / S.M.A.R.T, `station_id=5`). Группа typical — 94 маршрута,
   минимум 95 км (круг 190 ≈ 18 л) → минус. В **своей** библиотеке есть
   Кузнецкая ↔ Деловые линии **6 км** (круг 12, 1,14 л), но
   `typical_station_ids = NULL`. Фикс 24.08 фильтрует коридор только внутри
   группы; пустой коридор → `min(group)` = всё те же 190 км.
2. **Ступени км нет у этой машины.** 952 27.07: старт 1,43 л, +50 л, бак 55 л;
   28.07 снова +50 л. Lookahead требует дневной пробег **494–547 км**
   (плечо 247–273). У 952 после круга 450 сразу 560 (плечо 280, Вологда /
   Сергиев Посад). Солвер берёт 560 → **−1,21 л**. У Monjaro/848 плечо
   260/265 (круг 520/530) **есть**, солвер чужие `gsm_route` не читает.

Кандидаты солвера сегодня: `list_routes(vehicle_id=текущая)`. Сетка км —
история ПЛ **этой** машины, не парка.

## Recommended Direction

**Один набор кандидатов = все `gsm_route` парка.** Фильтр: коридор бака
(и окно lookahead, если оно есть). Ранжирование, чтобы 952 не ездила
каждый день «как Monjaro»:

1. В коридоре `[0 … tank]` (lookahead не имеет права выбрать маршрут вне окна).
2. Своя машина важнее чужой.
3. Тот же город, что у «почти подошедшего» своего рейса — важнее чужого
   города (27.07 952: Сергиев Посад 265 у 848 важнее Мантурово 260 у Monjaro).
4. База **Кузнецкая 18Б** (и зеркало B→A); нормализовать пробелы/`ул.`.
5. Нужный км: мойка (`q_today == 0`) — минимальный круг; выжиг — минимально
   достаточный `2×km`.

Норма литров — **всегда этой машины** (9,4 у 952, даже если км с 848).

Чужой маршрут **не копируем** в `gsm_route` этой машины. В ПЛ — `addr_a` /
`addr_b` / `km` на этот день; `route_id` пустой или без чужого id.
Жёлтый код: свой вне typical-группы → `balance_route`; чужая машина →
`borrowed_route`.

Если после фильтра никого нет (у Palisade на окне 494–547 донора нет) —
**красный** `manual_intervention`, как задумано. Не зажимать `fuel_end` в 0
(враньё в цепочке и в отчёте ГСМ). Не пропускать день.

**Справочник — отдельно, с человеком.** Солвер не плодит объекты. Если дыра
повторяется: сначала сверка штампа км на город, куда машина уже ездит
(952: Сергиев Посад 280 vs 848: 265 — разные дворы, один город);
потом «у соседа есть Мантурово 260 — возили?» → строка в справочник только
после «да». Гео — проверка км, не генератор адресов.

      16.07 без минуса; 02.07 сходится после 01.07 (короткий круг).
- [ ] Перегенерация июля 952 (якорь 30.06: 102 532 / 17,02 л): 27.07 бак ≥ 0,
      плечо в окне ~260–265, не круг 560; 28.07 не красный из‑за хвоста минуса.
- [ ] Регрессия `tests/test_gsm_generator.py` и май Palisade (коридор 24.08)
      остаются зелёными.
- [ ] Ранжирование «свой важнее» не отбирает чужой 6 км, когда свой 6 км есть.
- [ ] База Кузнецкая после нормализации ловит все четыре машины парка.

## MVP Scope

- `GsmGenerationService._load_routes`: грузить маршруты **всех** активных
  машин (или generator принимает `own` + `fleet`).
- `core/gsm/generator.py`: `_select_anchor_route_lookahead` — кандидаты =
  парк; пустой коридор группы не fallback на `min(group)` вне коридора;
  lookahead ∩ коридор; ранжирование как выше; warning `borrowed_route`.
- Frontend: подпись `borrowed_route` в `waybillWarnings.ts`.
- Тесты: мойка + пустая typical-группа + короткий в своей библиотеке;
  нет своей ступени + есть в парке с Кузнецкой; парк пуст → красный.
- Приёмка на копии БД, `force` по confirmed 30.06 не включать.

## Not Doing (and Why)

- **Зажим бака в 0** — месяц «закрыт», отчёт ГСМ разъедется с картой.
- **Автозапись чужого A→B в `gsm_route`** — засоряет историю машины;
  копировать только после явного «да» бухгалтера.
- **Ночёвка / соло-плечо** (день = 1×km) — закрыло бы 952 своим плечом 530,
  но это отдельная модель бланка; откладывали как фазу 2.
- **Склейка соседних заправок в один ПЛ** — ломает «1 день = 1 ПЛ»; ручной
  приём, не автомат.
- **Синтетические км / город из воздуха** — налоговая читает адреса.
- **0-км день мойки** — не нужно, если короткий круг в пуле парка есть.
- **Июньские «нет путевого» Monjaro** — якорь 30.06, не этот баг.
