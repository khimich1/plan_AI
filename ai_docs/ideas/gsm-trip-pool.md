# Пул поездок ГСМ (Excel по машинам)

> Ideation session: 2026-08-11  
> Контекст: архив `ГСМ/` — путевые листы 4 легковых авто завода + `Роману.xlsx`.

## Problem Statement

Как из архива путевых листов в `ГСМ/` получить по каждой машине полный и уникальный пул поездок (с адресами, временем, км, водителем, топливом и данными из `Роману.xlsx`), чтобы не разбирать сотни дублей `.xls` вручную?

## Recommended Direction

Один offline-скрипт → один общий `.xlsx` (колонка «машина» + фильтры). Внутри **три представления** одних данных:

1. **`facts`** — все заполненные строки ПЛ (факт рейса): машина, дата, водитель, топливо, адрес A, адрес B, время выезда/возврата, км, путь к исходному `.xls`.
2. **`routes_ab`** — каталог уникальных A→B + км; частота; типичное время; обогащение из `Роману.xlsx` (гос.номер, топливная карта, бак, нормы лето/зима).
3. **`rounds_aba`** — склеенные рейсы A→B→A внутри одного ПЛ (соседние строки с зеркальными адресами): км плеча, сумма км, времена обоих плеч. Непарные — лист `unpaired`.

Уникальность для каталога: **нормализованный адрес A + нормализованный адрес B + км**. Дата и время — история/статистика, не ключ.

Источник: только заполненные путевые (игнорировать папки `Не заполн` / `НЕ ЗАПОЛН`).

### Решения по открытым вопросам

- Один общий Excel, не 4 файла.
- `rounds_aba`: склейка по соседним зеркальным строкам в одном ПЛ.
- В `facts` обязателен путь к исходному `.xls`.

## Key Assumptions to Validate

- [ ] Игнор `Не заполн` даёт чистую картину (выборочно сверить 1 месяц × 1 машина)
- [ ] Нормализация адресов склеивает «ул.» / «улица» / пробелы без потери разных точек
- [ ] ≥80% заполненных дней парсятся как A→B→A; остальное уходит в `unpaired`
- [ ] Поля водитель/топливо стабильно читаются из шаблона ПЛ

## MVP Scope

- Offline-скрипт по `ГСМ/` → один `.xlsx`
- 4 машины + merge с `Роману.xlsx`
- Листы: `facts`, `routes_ab`, `rounds_aba`, `unpaired` (+ опционально краткая сводка)
- Колонки: машина, гос.номер, водитель, топливо, адрес A, адрес B, время, км, частота / примеры дат, путь к файлу (в `facts`)

## Not Doing (and Why)

- UI / API в «Шишов» — рано; сначала личный Excel
- Запись обратно в путевые листы — другой продукт
- Точный расход литров по чекам АЗС — в ПЛ только марка топлива и нормы
- Идеальный геокодер адресов — достаточно простых правил нормализации
- Автосоздание новых ПЛ из пула — после проверки каталога
