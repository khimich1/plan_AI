# Маршруты через свои АЗС (треки-через-заправку + крюк-аналитика)

## Problem Statement

Как нам показать на карте, что маршрут A→B физически проходит через свою типовую
АЗС — и по отклонению геометрии («крюк», км) отделять заправки по пути от
заправок вне пути?

Контекст: задел под будущий модуль (какой — открытый вопрос), поэтому формат
результата — чистый data-контракт (GeoJSON), а не разовая визуализация.

## Recommended Direction

**Ядро: waypoint-геометрия + варианты по станциям + авто-калибровка порога.**

1. Для каждого из 344 маршрутов с типовой АЗС строим OSRM-трек `A → АЗС → B`
   (координаты станции из `stations.geojson` как waypoint). Кэш-ключ трека
   расширяется идентификатором станции — прямые треки не пересчитываются.
2. Метрика `крюк_км = км_с_заездом − км_напрямую` пишется в properties маршрута
   и в попап АЗС. Это главный численный результат работы.
3. Калибровка: распределение крюков по 273 сопоставленным заправкам →
   предлагаемый порог «по пути» (ожидание: бимодальность, порог ~3-7 км).
   Заодно QA геокода: крюк > 30 км при городской АЗС = подозрение на кривые
   координаты, а не на нарушение.
4. Карта: слой «маршрут через АЗС» (линия через станцию), клик по АЗС
   подсвечивает обслуживаемые ею маршруты, клик по маршруту — его АЗС.

## Key Assumptions to Validate

- [ ] OSRM snap'ит точку АЗС к дороге без экзотических петель — проверить
  вручную на 5 маршрутах до полного прогона
- [ ] Км путевых листов включают заезд на АЗС — сравнить дельту «норма vs факт»
  в дни с заправкой и без на одном маршруте
- [ ] Распределение крюков бимодально — гистограмма после первого прогона;
  если сплошное, порог фиксируем экспертно (5 км) и помечаем как условный
- [ ] У маршрута ровно одна типовая АЗС (подтверждено данными: 344/344)

## MVP Scope

**Внутри:**
- `ГСМ/geo_cache/routes_via.geojson` — FeatureCollection: одна фича на пару
  «маршрут × типовая АЗС», properties: маршрутные поля + `азс_адрес`,
  `км_напрямую`, `км_с_заездом`, `крюк_км`, `крюк_по_пути` (bool по порогу)
- `build_gsm_routes_map.py`: слой via-треков + связка кликов АЗС↔маршрут +
  поле крюка в попапах; порог — параметр CLI (`--via-threshold-km`)
- Отчёт калибровки в stdout/MD: гистограмма крюков (текст), топ-10 аномалий,
  рекомендованный порог
- Тесты: кэш-ключ со станцией, сборка via-фич, метрика крюка, пороговый флаг

**Снаружи:**
- Планировщик дозаправки (бак, нормы, «где заправиться») — следующий модуль
- Авто-геокод 25 трассовых адресов — только ручной `stations_manual.json`
- Перенос карты в React-приложение — отдельная задача

## Not Doing (and Why)

- **Коридорная подсветка вместо геометрии** — не отвечает выбранному смыслу
  («линия должна идти через заправку»), оставляем как fallback, если OSRM
  будет строить мусор
- **АЗС-центричный разрез для закупщика** — другой пользователь, другая
  задача; данные (`stations.geojson`) уже готовы, визуал — по запросу
- **Комбо-заезды A→АЗС1→АЗС2→B** — в данных таких дней единицы; при появлении
  кэш-ключ расширяется списком станций
- **Реалтайм/GPS** — источник истины остаётся путевой лист + транзакции

## Open Questions

- Что за новый модуль — формат `routes_via.geojson` проектируем как
  публичный контракт, но без знания потребителя можем не угадать поля
- Нужен ли via-трек для маршрутов, чья типовая АЗС без координат
  (сейчас: пропускаем, считаем в отчёте)?
- Порог применять к дельте км дня (рейсы_дня.дельта_л) — связывать ли
  «вне пути» с перерасходом в том же релизе?

## Данные на старте (замер 2026-08-12)

- 610 маршрутов, 344 с типовой АЗС, 49 точек станций с координатами
- 273 сопоставленные заправки для калибровки, 236 транзакций вне поездок
- OSRM: до ~344 новых треков, кэш `ГСМ/geo_cache/routes.geojson` расширяется

## Статус: реализовано 2026-08-12

- `route_stations.json` (feed): 408 связей маршрут↔АЗС (топ-3 на маршрут)
- `routes_via.geojson` (map): 210 via-треков A→АЗС→B, крюк_км против
  OSRM-дистанции прямого трека; чистка устаревших геометрий по cache_key
- Калибровка: медиана крюка 4,9 км; авто-порог 13 км (распределение оказалось
  НЕ бимодальным: провал на 2-3 км, масса на 5-13 км — «заправка у базы/в городе»
  съезжает с прямой; порог стоит пересмотреть экспертно, `--via-threshold-km`)
- Карта: слой «Через АЗС» (пунктир: зелёный ≤ порога, красный > порога),
  клик по станции подсвечивает её маршруты
- Пойман баг геокода: короткие plus-code восстанавливались от референса без
  региона («Сусанино» уезжало в Ленобласть, крюк 1596 км) — референс теперь
  полный хвост адреса
- Открыто: 150 связей без координат (84 станции — трассовые адреса,
  ждут `stations_manual.json`; 54 — концы маршрутов)
