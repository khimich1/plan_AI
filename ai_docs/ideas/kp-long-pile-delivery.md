# Доставка свай длиннее 13 м

> Ideation: 2026-09-23  
> Для кого: менеджер КП  
> Статус: план [`../develop/plans/2026-09-23-kp-long-pile-delivery.md`](../develop/plans/2026-09-23-kp-long-pile-delivery.md), спека [`../specs/kp-long-pile-delivery.md`](../specs/kp-long-pile-delivery.md)  
> Смежные: [`pile-bridge-trip-calculation.md`](pile-bridge-trip-calculation.md), `core/pile_trip_pricing.py`, `pile_catalog`

## Problem Statement

**Как менеджеру КП оставить для свай до 13 м один тариф рейса, а для каждой длины длиннее 13 м ввести свою цену доставки, спрашивая число машин только когда нормы загрузки нет?**

Сейчас все сваи делят одно поле «стоимость рейса». Рейсы считаются по норме «шт. на 20 т», остатки известных марок складываются и делятся на 19 800 кг. У `С160.30`, `С160.35` и `С160.40` нормы нет: система спрашивает число машин, и пока ответа нет, доставка всех свай равна нулю.

## Recommended Direction

Сваи до 13,0 м включительно остаются на общем тарифе `pile_logistics_cost` и на нынешней формуле рейсов. Сваи длиннее 13,0 м из этого котла выходят.

В этом КП у каждой такой длины своё поле цены доставки. Это тариф рейса, не цена изделия и не рубли за штуку. Несколько строк одной длины делят один тариф. Если в справочнике есть «шт. на 20 т», рейсы считаются сами. Если нормы нет, менеджер вводит число машин, как сейчас для 16-метровых. Доставка длины = тариф × рейсы.

Незаполненная длина не обнуляет доставку остальных свай. В заводскую таблицу норму для 16 м не подставляем: там по-прежнему прочерк.

### Утверждённые решения

| Тема | Решение |
|------|---------|
| Кто вводит | Менеджер КП, в этом предложении. Справочника тарифов нет |
| Порог | Строго длиннее 13,0 м. Свая ровно 13,0 м остаётся в общем котле |
| Что за цена | Рубли за рейс этой длины |
| Одинаковая длина | Несколько строк одной длины — один тариф |
| Рейсы | Считаем сами, если есть `pcs_per_20t`. Иначе поле «машин» |
| Короткие сваи | Прежний тариф и прежняя формула. Длинные в этот котёл не входят |
| Дырка | Нет тарифа или числа машин у длины — в ноль только она |
| Справочник | Прочерк у `С160.30`, `С160.35`, `С160.40` не заполняем |

## Key Assumptions to Validate

- [ ] Длиннее 13,0 м — строго больше 13 м. `С130.*` остаётся в общем котле
- [ ] Две строки одной длины при разном сечении или нагрузке делят один тариф
- [ ] У 14 м и 15 м норма уже есть, вопрос про машины для них не появляется
- [ ] Вопрос «сколько машин» остаётся только у длин без `pcs_per_20t`: `С160.30`, `С160.35`, `С160.40`

## MVP Scope

В итогах КП: обычное поле рейса свай для длин до 13 м. Для каждой длины длиннее 13 м — тариф и, если нормы нет, поле «машин». В сумме и в PDF отдельная строка доставки на каждую такую длину. Пока по длине нет тарифа или числа машин, в ноль уходит только она.

## Not Doing (and Why)

- Общий тариф на все длины сразу — 14 м и 16 м тогда стоят одинаково
- Цена доставки за штуку без рейсов
- Справочник тарифов, который ведёт не менеджер КП
- Подстановка «шт. на 20 т» для 16-метровых свай — в заводской таблице прочерк
- Тот же механизм для плит
- Раскладка длинномера в кузове
