# Визуализация укладки в логистике

> Ideation: 2026-08-02  
> Статус: направление согласовано, mockup ниже  
> Связано: `core/shipment_packing/`, `shipment-propose-v2.md`, `ShipmentDrawer`

## Problem Statement

**How Might We:** показать логисту и складу физическую укладку плит в кузов 13,2 м сразу после «Предложить состав», чтобы на площадке было меньше перекладок и ошибок?

## Решения ideation (2026-08-02)

| Вопрос | Решение |
|--------|---------|
| Кому | Логист + склад |
| Когда показывать | Сразу после «Предложить состав» |
| Направление MVP | **Гибрид:** порядок погрузки + простая схема + 2-й лист XLSX |
| Пересчёт при правках | **Только auto-propose** — при ручных правках схему не показываем |
| Успех | Меньше ошибок/перекладок на площадке |
| Детализация схемы | Наглядно; вид «сверху + ярусы по клику» (см. mockup) |

## Recommended Direction

Expose **layout metadata** из `core/shipment_packing` (stacks → tiers → units) в ответ propose и в snapshot.

В UI карточки рейса — блок **«Укладка в кузов»** сразу после успешного propose:

1. **Полоска кузова сверху** — пропорционально 13,2 м, штабели как цветные блоки.
2. **Раскрытие штабеля** — клик по блоку → ярусы с марками плит.
3. **Порядок погрузки** — нумерованный список шагов для склада.
4. **2-й лист XLSX** «Лист отгрузки» — та же схема + порядок для печати.

При **ручных правках** состава блок скрывается (или показывает «Схема актуальна для предложенного состава — нажмите „Предложить состав“»). Live-пересчёт и валидация ручного состава — **не в MVP**.

### Лист XLSX (2-я вкладка «Схема укладки»)

Таблица шагов + упрощённая ASCII/ячейки «штабель × ярус» для печати на A4.

## Key Assumptions to Validate

- [ ] Склад использует распечатку из системы — опрос 3 крановщиков после недели пилота
- [ ] Порядок погрузки + простая схема снижают misload сильнее, чем только таблица состава
- [ ] Логистам достаточно схемы только от propose (ручные правки без схемы — приемлемо)

## MVP Scope

**In:**

- `layout` в `ShipmentProposeResponse` / `propose_snapshot`
- Блок «Укладка в кузов» в `ShipmentDrawer` (после propose)
- 2-й лист в `export_shipment_sheet_xlsx`
- Golden-тест: layout metadata для эталонного рейса (9 плит из ideation)

**Out:**

- Пересчёт схемы при ручных правках (debounced live layout)
- Drag-and-drop редактор укладки
- 3D / фотореализм
- ГОСТ-паспорт для водителя
- Переиспользование `viz_modules` (другая предметная область)

## Not Doing (and Why)

| Не делаем | Почему |
|-----------|--------|
| Live layout при ручных правках | Out of scope propose v2; пользователь выбрал «только propose» |
| Редактор перетаскивания | Scope ×5, не нужен для проверки гипотезы misload |
| `viz_modules` для фуры | Production 2D ILP ≠ truck stacking |
| Вид «сбоку» как единственный | Сложнее UI; достаточно сверху + раскрытие ярусов |
