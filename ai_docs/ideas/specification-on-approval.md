## Problem Statement

Как сделать так, чтобы менеджер на согласовании собрал спецификацию к договору из заготовок с листов — или из своего текста — и скачал черновик, не дожидаясь номера счёта из 1С и не переписывая юридические абзацы руками.

## Recommended Direction

Кнопка «Спецификация» стоит на карточке заказа в статусе «на согласовании». Менеджер выбирает одну схему оплаты, один срок поставки и один вид поставки. Программа подставляет даты, доли и сроки в готовые предложения и сама пишет пропись. Свободное поле одно: «свой текст» для оплаты, когда схема с листа не легла. Так в образец № 650 попали два транша рублями, а не проценты. Сгенерированный абзац менеджер не редактирует.

Файл — Excel в вёрстке спецификации № 650 от 18.09.2026: преамбула, таблица изделий, условия, подписи. Покупатель, «в лице…», номер и дата договора берутся из действующего договора контрагента. Строки, цены с НДС и итог — из карточки КП. Номер счёта в шапке остаётся пустым, пока пусто `order_number_1c`. Когда номер появится, тот же файл скачивается снова, условия заново не спрашиваются. Короткие «Условия оплаты» и «Условия поставки» из конструктора КП в документ не копируются: «стандартные» только заранее нажимают 100% предоплату, слово «самовывоз» заранее нажимает самовывоз.

«В производство» по-прежнему требует отметку оплаты и номер счёта. К этому добавляется сохранённая спецификация: оплата, срок и вид поставки. Процентные схемы при изменении состава КП пересчитываются сами. Свой текст со старыми суммами в производство не пускает, пока его не откроют и не сохранят снова.

## Как устроен выбор

**Оплата, одна кнопка.**

1. 100% предоплата. Окон нет.
2. Частичная предоплата. 50% зашиты в схему.
   - 50% до даты и 50% за N дней до начала отгрузки. По умолчанию N = 3, число — окно, пропись из числа.
   - 50% до даты, затем одна кнопка из 10 / 20 / 30 / 40% до своей даты. Остаток — в течение N календарных дней после поставки партии. Партия — товар по одному УПД. По умолчанию N = 5. Рубли считаются от текущего итога карточки.
3. Отсрочка N календарных дней. По умолчанию 45.
4. Свой текст.

Свободного процента нет. Нестандартные доли живут только в своём тексте.

**Срок поставки, одна кнопка.**

1. Не позднее даты.
2. Начало с даты, по N свай в неделю или в день. Кнопка видна только если в КП есть сваи.
3. В течение N календарных дней со дня, следующего за поступлением денег на расчётный счёт в полном объёме. По умолчанию N = 10, пропись из числа.

**Вид поставки, одна кнопка.**

- Самовывоз со склада готовой продукции. Адрес уже есть: 150020, г. Ярославль, проезд Домостроителей, дом 1, строение 3.
- Доставка на объект покупателя по адресу. Адрес — окно. Стоимость доставки включена в стоимость товара.

**Связка срока с оплатой.**

- 100% предоплата и свой текст: к сроку «не позднее даты» дописывается условие образца — поставить в этот срок, если предоплата пришла полностью в срок спецификации.
- Частичная предоплата: то же, но только про авансы, названные в условиях оплаты, не про всю цену. Остаток после УПД этой фразе противоречит.
- Отсрочка: фразу не дописывать.
- Срок «через N дней после поступления денег»: фразу не дописывать, связь с оплатой уже внутри схемы.

Марка бетона в шапке — только для свай и только когда на всех строках она одна.

## Key Assumptions to Validate

- [ ] Менеджер КП — единственный, кто нажимает кнопку. Успех для него: условия сохранены и скачан Excel с пустым номером счёта.
- [ ] Клиент принимает черновик спецификации без номера счёта. Номер ставится повторным скачиванием, когда он ляжет в `order_number_1c`.
- [ ] Кнопок 10 / 20 / 30 / 40 хватает на обычные сделки. Разбиение суммой, как в № 650, редкое и живёт в своём тексте.
- [ ] Сроки 3, 5, 45 и 10 — годные значения по умолчанию, а не норма, которую нельзя менять.
- [ ] На согласовании действующий договор уже есть: туда заказ попадает только через «Отправить в 1С», а та без договора не проходит. Подписанта и основания из договора хватает для преамбулы без второго «в лице».
- [ ] Цена строки в Excel — цена карточки с НДС, тот же состав, что уйдёт в счёт. Пропись итога и НДС совпадает с таблицей с точностью до копейки округления по строкам.
- [ ] Свой текст со старыми суммами опаснее, чем лишний клик. Ворота перед производством на неподтверждённый свой текст менеджер примет.

## MVP Scope

Кнопка на карточке «На согласовании», сохранение выбранных схем и окон, сборка Excel по образцу № 650, пустой номер счёта, повторное скачивание с номером без повторного выбора, запрет «В производство» без сохранённых оплаты, срока и вида поставки, пересчёт процентов от текущего итога, повторное сохранение своего текста после изменения состава.

## Not Doing (and Why)

- Поле ввода номера счёта и живой обмен с 1С — номер по-прежнему ждёт обратный JSON в `order_number_1c`.
- Правка сгенерированного абзаца руками — это экран 1С, из которого в образце вышла неверная пропись. Свой текст — единственное свободное место.
- Копирование `payment_conditions` и `delivery_conditions` конструктора КП в спецификацию — там другая, короткая фраза. Они только заранее нажимают кнопку.
- Свободный процент и свободное число свай на заказе из плит — доли закрыты меню, ритм свай и марка бетона не показываются без свай.
- PDF или docx вместо Excel — образец, с которым сверяемся, это xlsx.
- Отправка спецификации в 1С — на этом шаге файл для клиента и для карточки.
- Отдельная проверка «есть ли договор» внутри кнопки — она уже стоит на входе в статус.
- График поставки и готовность КП на этом экране — они про цех, цех на согласовании по-прежнему закрыт.
