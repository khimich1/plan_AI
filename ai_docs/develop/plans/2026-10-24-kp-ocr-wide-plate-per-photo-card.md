# Implementation Plan: Карточка широкой плиты на каждом фото

**Created:** 2026-10-24  
**Spec:** [../../specs/kp-ocr-wide-plate-per-photo-card.md](../../specs/kp-ocr-wide-plate-per-photo-card.md)  
**Goal:** После apply на первом фото карточка «Нестандартная ширина» открывается на втором, и список второго не подменяется.  
**Status:** IMPLEMENT done  
**SDD:** SPECIFY ✅ · PLAN ✅ · IMPLEMENT ✅

## Overview

`wide_plates_resolved` один на черновик. Resolve ставит его всегда, а overlay не снимает флаг, если марка уже есть в `wide_plate_lines`. Карточка второго фото пропадает, подсветка остаётся.

Клиент помнит ключи марок, которые уже применили на каждом фото. Чужое фото этот набор не наследует. Apply пишет текст только открытого фото и шлёт решения только его списка.

`force_wide_resolved` не менялся. Если на двух фото одна и та же марка, сервер может переписать обе партии, но на экран второго фото этот текст не кладётся. «Список верен» потом отправляет текст страниц.
