## Overview

Текстовая карточка сначала читается правилами: значение со следующей непустой строки, подозрительная строка в поле не попадает. Модель зовётся один раз и только если после этого осталась дырка. Два банка — кнопки связок, первый молча не выбирается. На экране фраза называет ещё адрес, банк, должность и ФИО, а у Word слева текст карточки.

## Architecture Decisions

- **Контроль цифр тот же.** `accept_*` не ослаблять. Связка проходит через `accept_bundle`: нет ключа счёта и БИК — кнопки нет.
- **Подозрительное снимается до `fields`.** Адрес из скобок или обрывка подписи, банк с «р/с», «к/с», «БИК» или 20 цифрами, почта с телефоном или вторым адресом — в `doubtful`, в полях пусто.
- **Два и больше связок не пишут четыре поля.** `banks` в ответе. Один блок по-прежнему заполняет поля. Один БИК на два счёта связку не выбирает. Два корсчёта не кладут первый в `fields`.
- **Два контрольно верных ИНН не замораживаются.** Значение может лежать в поле, `inn` остаётся в `doubtful`.
- **Модель — текстовый чат без картинки.** `complete_text_json` у того же `OCR_PROVIDER`. Чистая карточка провайдера не вызывает. Ответ пишет только запрошенные ключи и не затирает замороженную цифру. Ошибка и пустой ответ оставляют локальный разбор. Адрес, должность и ФИО из модели остаются в `doubtful`.
- **Тесты сервиса с подменой зрения не ходят в сеть.** Если в `SupplyContractService` передан `card_recognizer`, а текстовый провайдер нет, добор дыр не открывает живой API. Боевой путь (`card_recognizer is None`) при дырке зовёт провайдер.
- **Экран.** Фраза: прежние цифры, затем юридический адрес, банк, должность, ФИО. При `banks.length > 1` эти четыре ключа в фразу не входят. Рамка гаснет по правке текста. Слева у файла без картинки — `source_text`, без масштаба. Пустой ИНН в ответе не затирает ИНН контрагента и остаётся жёлтым, если ключ в `doubtful`.

## Dependency graph

```
соседняя строка и подозрительное
    │
    ├── связки, два ИНН, source_text
    │       │
    │       └── один текстовый добор дыр
    │               │
    │               └── фраза, кнопки, рамка, текст слева
    └── фото и PDF без текста не входят
```

## Risks and Mitigations

| Risk | Impact | Mitigation |
|---|---|---|
| xlsx-фикстура с дырками начнёт звать живой API | Тест упадёт или уйдёт в сеть | Добор только если нет подменённого `card_recognizer` либо передан текстовый провайдер |
| Два корсчёта раньше писали первый в поле | Старый контракт врёт | Тест обновить под пустое поле, контроль длины не ослаблять |
| Фраза начнёт называть адрес там, где тест ждал тишину | Ложный провал UI | В тесте «нет фразы» оставить только имя и почту; адрес проверить отдельным тестом |
| `source_text` у фото заменит масштаб | Сверка снимка сломается | Колонка текста только без картинки; путь зрения не менять |
