## Контракт API (обязателен для обоих работников)

- `POST /api/v1/gsm/report/usage`
  body: `{ "period_from": "YYYY-MM-DD", "period_to": "YYYY-MM-DD",
           "vehicle_ids": [int, ...] | null }`
  (null = все активные машины)
  → 200, `Content-Type: application/zip`, имя файла вида
  `gsm_usage_report_YYYY-MM-DD_YYYY-MM-DD.zip`
  → 4xx с `{"detail": {"code": ..., "message": ...}}` по существующему
  паттерну gsm-эндпоинтов
- В zip: `Отчет по использованию ГСМ <госномер>.xls` на машину + путевые
  листы за период (как в существующем экспорте ПЛ).

## Правила домена (из идеи — сверяйся с ней)

- 1 строка отчёта = 1 confirmed ПЛ; «Примечание» = дата («04 мая»),
  колонка назначения = пункт назначения маршрута ПЛ.
- Остатки/одометр — сквозная цепочка (apply_chain) от последнего confirmed
  якоря до периода; эталон: 848, май 2026.
- «Расход по факту» = «по норме». «Получено» = транзакции карт, дата может
  съезжать ±1 день к ближайшей строке.
- ИТОГО + дубль-строка по марке бензина. Подписанты в шаблоне:
  Шишов А.В. / Никифорова Е.А.; дата утверждения = последний день периода.
- Пробег — из ПЛ (нормативный), НЕ из телематики.
