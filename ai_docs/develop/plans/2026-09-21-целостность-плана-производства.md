## Overview

Три бага целостности на пути «заказ → план → БД», диагноз подтверждён живыми данными
(deep-dive 2026-09-21):

- **A24** — марка бетона теряется при сборке track items (`from_plan.py:676/747/944`
  копируют `kp_id`/`plate_name`, но не `concrete_grade`; skip-путь `plate_attribution.py:319`).
- **A25** — кросс-КП мисатрибуция одинаковых плит → сирота `kp_plates.id=197` +
  призрак на трассе (кейс КП#4/#5, план `plan_20260904_124248`).
- **A26** — слепота детекции surplus (`coverage_verify.py:60`); ILP невиновен
  (доказано: `ilp_model.py:261` точный `==`, все vars `LpInteger`).

Четыре PR в порядке «атрибуция → детекция → источник+сеть → сигнал» (D-order).

## Architecture Decisions

- **D-order:** марка → surplus-наблюдаемость → **источник (unit_id) → гейт** → бейдж.
  Зависимость «источник → гейт» жёсткая: enforce без источника запрещён.
  Каждый PR откатываем независимо, отдельная ветка/коммит на PR.
- **D-ilp:** ILP не трогаем — невиновна, доказано кодом (`ilp_model.py:261`, `LpInteger`).
- **D-unit-id:** источник A25 — track-side backfill матчит по `unit_id`
  (`finalize.py:224–226` ↔ `from_plan.py:693–694`): предпочитает `kp_id`, выбранный
  assignment-side для того же `unit_id`; геометрия — только fallback.
  Reconciliation-pass перед mark — вторая линия (audit-лог каждого движения).
- **D-gate-env:** `PLAN_COMMIT_GATE=off|observe|enforce`, default `observe`;
  enforce: откат пометок обязателен (паттерн `plan_commit.py:734–739`),
  legacy (`tracks_by_day=None`) → skip+log, ошибка с remediation.
- **D-gate-scope:** новое — item→pool, NULL-day, rescue-leftovers в отчёт;
  pool→item уже существует (`:711–743`) — не дублируем.
- **D-coverage:** PR-2 — только наблюдаемость (error-лог + отчёт); `opt_ok` не
  меняется; нормализация ключей унифицируется; surplus по `set(coverage)|set(demand)`.
- **D-hash:** приёмка PR-1/PR-2 — hash по layout-полям (порядок, геометрия, qty),
  ИСКЛЮЧАЯ атрибутивные (`concrete_grade`, `kp_id`, `kp_plate_id`) — иначе приёмка
  невыполнима по построению (propagation добавляет поле).
- **D-grade-policy:** группировка трасс по марке НЕ входит — ждёт решения завода.
- **Процессные:** коммиты — по просьбе; `./run+logs.sh` не убивать; новых pip/npm нет;
  запуск ремонтного скрипта по БД — ask first.
