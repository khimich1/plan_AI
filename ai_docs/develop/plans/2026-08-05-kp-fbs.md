## Goal

Менеджер создаёт **отдельное КП на ФБС** через web-мастер: picker «ФБС» → текст/фото/ИИ → после «Список верен» preview с классом бетона → client → PDF/XLSX → архив. Цены только из листа «Прайс» ФБС. Default grade **B25**. Production — только plates.

## Architecture decisions

1. **`product_type = "fbs"`**, UI «ФБС»; immutable after create.
2. **Clone piles/bridge_piles** for domain/UX (grade per-line, `/fbs/grades`, PDF with grade).
3. **Clone marches/bridge_piles wiring** for multi-product.
4. **Separate tables** — `fbs_prices` (pb.db), `kp_fbs` (plita.db).
5. **Import only sheet «Прайс».** Grades: `7.5→B7_5`, `20→B20`, `22.5→B22_5`, `25→B25`. Skip zero/empty.
6. **No alias/variant_group** (unlike bridge piles).
7. **Normalize for lookup:** spaces, case, `Т`↔`T`; display = manager typed.
8. **Default grade B25** if priced; else single available / first.
9. **Bulk grade:** apply where available; skip + warning otherwise.
10. **OCR** — `fbs_format_prompt.py`.
11. **No generic framework.**
12. **Shared `kp_id`**; production whitelist unchanged.
