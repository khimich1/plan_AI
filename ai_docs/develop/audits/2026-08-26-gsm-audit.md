## High Priority Issues (fix soon)

### [A1] God-сервис жизненного цикла ПЛ вместо генерации

- **Category**: Architecture
- **Location**: `app/services/gsm_generation_service.py` (~1016 строк: `generate`/`generate_bulk` 66–279, `list_waybills` 281–303, `patch_waybill` 305–401, `create_waybill` 403–479, `confirm_waybill` 481–505, `_rechain_downstream` 566+)
- **Impact**: нарушение SRP — сервис генерации совмещает CRUD, подтверждение и пересборку цепочки ПЛ
- **Fix**: выделить `GsmWaybillService`; в `GsmGenerationService` оставить оркестрацию generator + persist

### [A2] God-модуль доменного генератора

- **Category**: Architecture
- **Location**: `core/gsm/generator.py` (~1275 строк, 40+ функций)
- **Impact**: монолитный доменный модуль затрудняет тестирование, ревью и точечные изменения
- **Fix**: разбить на `anchor_selection.py`, `burn_in.py`, `day_emit.py`, `route_ranking.py`

### [A3] Блокирующий экспорт LibreOffice в HTTP-запросе

- **Category**: Architecture
- **Location**: `app/services/gsm_export_service.py` (`run_soffice` 52–87, `export_zip` 129+); `app/services/gsm_report_service.py` (`build_usage_zip` 92–196, soffice per vehicle 158–160)
- **Impact**: длительные синхронные HTTP-запросы, блокировка воркеров, плохая масштабируемость
- **Fix**: фоновая задача + polling/download

### [A4] Дублирование доменной логики на фронте с расхождением контракта сезона

- **Category**: Architecture
- **Location**: `frontend/src/features/gsm/lib/downstreamPreview.ts`, `exportGate.ts` vs `core/gsm/season.py`; API отдаёт только `season_mode` + `season_switched_at` (`app/schemas/gsm.py` 277–278)
- **Impact**: фронт и бэкенд могут по-разному интерпретировать сезон; риск некорректного preview/gate при month-close
- **Fix**: `season_switches[]` в API или server-side preview/gate

### [A5] Импорт транзакций без unit-of-work

- **Category**: Architecture
- **Location**: `app/services/gsm_transaction_service.py` 82–114; `app/repositories/gsm_repository.py` 404–425 (commit per row)
- **Impact**: частичный импорт при ошибке, неконсистентное состояние БД
- **Fix**: одна транзакция + batch insert

### [S1] DoS через синхронный soffice в HTTP

- **Category**: Security
- **Location**: `app/services/gsm_export_service.py` 52–68, 200–250; `app/services/gsm_report_service.py` 147–176; `app/api/v1/endpoints/gsm.py` 613–662
- **Impact**: злоумышленник может исчерпать воркеры и CPU длительными экспортами (связано с [A3])
- **Fix**: очередь + лимиты `vehicle_ids`/периода

### [S2] DoS через импорт без лимита числа файлов и строк

- **Category**: Security
- **Location**: `app/api/v1/endpoints/gsm.py` 147–166; `app/services/gsm_transaction_service.py` 39–114; `commercial_upload_validation.py` 67–83 (50MB/file, unlimited files); `app/repositories/gsm_repository.py` 391–424
- **Impact**: загрузка неограниченного числа/объёма файлов может исчерпать память и БД
- **Fix**: max files/rows/total bytes + batch tx + rate limit

### [Q1] Расхождение округления литров: Math.round vs Python banker's round

- **Category**: Code Quality
- **Location**: `frontend/src/features/gsm/lib/downstreamPreview.ts` 22–25, 70–71 vs `core/gsm/balance.py` 16–17
- **Impact**: preview на фронте может не совпадать с бэкендом; пользователь видит «правильные» цифры в UI, но экспорт/отчёт отличаются
- **Fix**: единая функция округления (server-side preview или shared spec + тесты)

### [Q2] Несогласованная обработка битого `season_switches`

- **Category**: Code Quality
- **Location**: registry молча `[]` vs generation/report raise `gsm_settings_invalid`
- **Impact**: одни и те же битые настройки ведут себя по-разному в разных частях модуля
- **Fix**: единая политика валидации и ошибки во всех сервисах
