## Высокий приоритет (исправить до следующего релиза)

### Архитектура (5 пунктов высокой серьёзности)

#### [A1] Нарушение SRP: монолит `visualize_plan()`
**Место**: `core/visualization.py`, функция `visualize_plan()` (порядка строк 12–450+)  
**Серьёзность**: Высокая  
**Влияние**: нарушен принцип единственной ответственности; в одной функции смешаны расчёт раскладки, ограничения, отрисовка и отладка. Сложно тестировать, расширять и сопровождать.  
**Причина**: вся логика визуализации собрана в одной точке входа.  
**Исправление**: вынести подфункции: `_calculate_layout()`, `_apply_constraints()`, `_render_canvas()`, `_build_debug_output()`.

#### [A2] Тесная связь с глобальным конфигом (`cfg`)
**Место**: множественные обращения к `cfg` по файлу  
**Серьёзность**: Высокая  
**Влияние**: прямая зависимость от изменяемого глобального `cfg`; нет слоя абстракции. Изменение структуры конфига ломает визуализацию без типобезопасности и валидации.  
**Причина**: прямой доступ к атрибутам (`cfg.OPT_CASCADING_PLAN`, `cfg.paths` и т.д.) вместо внедрения зависимостей.  
**Исправление**: передавать конфиг параметром; типизированный словарь или dataclass. Ввести абстракцию `get_config_for_visualization()`.

#### [A3] Два источника заказов (legacy-путь)
**Место**: фрагменты загрузки заказов, интеграция с `core/optimization.py`  
**Серьёзность**: Высокая  
**Влияние**: два пути загрузки (`primary_orders` vs fallback на `bot.data`); дублирование логики. Путает сопровождение.  
**Причина**: поэтапный рефакторинг без зачистки.  
**Исправление**: объединить загрузку заказов в одну утилиту, например `core/order_loader.py`.

#### [A4] Неиспользуемая функция: `optimize_cuts_pulp()`
**Место**: `core/visualization.py` (участок с мёртвым кодом)  
**Серьёзность**: Высокая (мёртвый код)  
**Влияние**: лишняя нагрузка на сопровождение; неясно, зачем оставлено.  
**Причина**: замена подхода к оптимизации без удаления старого кода.  
**Исправление**: удалить `optimize_cuts_pulp()` и связанные неиспользуемые импорты (например, `pulp`).

#### [A5] Дублирование: `split_sequence_into_tracks()`
**Место**: `core/visualization.py` и другие модули  
**Серьёзность**: Высокая  
**Влияние**: одна и та же логика в нескольких местах; нарушение DRY.  
**Причина**: копирование; нет общей утилиты.  
**Исправление**: перенести в `core/sequences.py` или `core/utils.py` и импортировать везде.

### Безопасность (2 пункта высокой серьёзности)

#### [S1] Риск обхода путей в `output_dir`
**Место**: построение выходных путей  
**Серьёзность**: Высокая  
**Влияние**: параметр `output_dir`, контролируемый пользователем, не валидируется; возможна запись в произвольные места ФС.  
**Причина**: нет санитизации путей; доверие к `cfg.paths.output`.  
**Исправление**: валидация путей — все выходы строго внутри разрешённого каталога.
```python
from pathlib import Path

def _validate_output_path(base_dir: str, file_path: str) -> Path:
    base = Path(base_dir).resolve()
    target = (base / file_path).resolve()
    if not str(target).startswith(str(base)):
        raise ValueError(f"Path traversal detected: {file_path}")
    return target
```

#### [S2] Инъекция формул в CSV
**Место**: логика экспорта CSV  
**Серьёзность**: Высокая  
**Влияние**: значения, начинающиеся с `=`, `+`, `@`, могут выполняться как формулы в Excel/Sheets; инъекция через данные заказа.  
**Причина**: прямой вывод ячеек без санитизации.  
**Исправление**: префикс `'` для небезопасных строк или библиотека санитизации.
```python
def _sanitize_csv_value(value):
    if isinstance(value, str) and value and value[0] in ('=', '+', '@', '-'):
        return "'" + value
    return value
```

### Качество кода (3 пункта высокой серьёзности)

#### [Q1] Пробел в обработке ошибок: необработанный `KeyError`
**Место**: распаковка структуры заказа  
**Серьёзность**: Высокая  
**Влияние**: `KeyError` при отсутствии ключей; пайплайн визуализации падает.  
**Причина**: слабая проверка типов; нет схемы входа.  
**Исправление**: явные проверки перед распаковкой.
```python
required_keys = ['order_id', 'product', 'qty']
for key in required_keys:
    if key not in order:
        raise ValueError(f"Order missing required field: {key}")
```

**Серьёзность**: Высокая  
**Исправление**: вынести в `_split_order_by_branch()`.

#### [Q3] Неиспользуемая минимальная длина дорожки
**Место**: параметр/константа `min_track_length`  
**Серьёзность**: Высокая (мёртвый код)  
**Исправление**: удалить неиспользуемый параметр/переменную.
