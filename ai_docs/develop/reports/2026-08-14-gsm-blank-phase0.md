## Ручные наблюдения (агент, 2026-08-14)

1. **Топливная цепочка бланка подтверждена формулами:**
   `стр.2!C19 = SUM(I5:J7)` (итого км) → `стр.1!BS41 = 'стр.2'!C19*9.5/100`
   (расход по норме) → `стр.1!BS39 = BS34+BS38-BS41` (остаток при
   возвращении) и `стр.1!BY45 = BZ20+'стр.2'!C19` (одометр при возвращении).
   Сценарий B менял км первого плеча (95→105) — все 4 зависимые ячейки
   пересчитались корректно. Это ровно производственный сценарий: генератор
   пишет км плеч + «выдано», формулы считают остальное.
2. **Норма расхода захардкожена в формуле** `BS41` (`*9.5/100` — летняя норма
   Monjaro). Для прода: один шаблон + патч формулы при экспорте
   (норма машины/сезона подставляется строкой) — либо 4 машины × 2 сезона
   шаблонов. Решение — за `gsm_export_service`, патч дешевле.
3. **8 расхождений empty→0.0** — служебные IF-формулы колонки CC
   (`=IF(C27<>"",C27,"")`): LibreOffice хранит пустой результат как 0.
   На печатной форме не видно (проверено по PDF, стр. 1–2 без артефактов).
4. **LibreOffice quirk:** `--convert-to 'xls:"MS Excel 97"'` падает с
   `impl_store 0x81a`; голый `--convert-to xls` использует тот же фильтр
   и работает. Зафиксировано в docstring скрипта.
5. **Формул 19, не 137** — ранняя прикидка байт-сканом BIFF завышала
   (ложные срабатывания 0x0006 в бинарных данных).
6. **Вёрстка переживает round-trip** — визуальная проверка PDF: обе
   страницы бланка (лицевая + оборотная с плечами маршрута) без искажений.
