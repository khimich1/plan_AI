# Отчёт: Функция расчёта стоимости рейса доставки грузов

**Дата:** 2026-05-05  
**Статус:** ✅ Реализовано  
**Категория:** Функция ценообразования

---

## Краткое описание

Реализована функция расчёта стоимости рейса доставки грузов на основе веса груза. Введена метрика «стоимость рейса» (цена за один стандартный рейс грузоподъёмностью 18,6 тонн) и формула расчёта количества рейсов с округлением в большую сторону.

---

## Что изменилось

### Логика расчёта
- **Формула количества рейсов:** `trips = ceil(weight_kg / 18600)`
- **Формула итоговой стоимости:** `total_cost = trip_cost × trips`
- **Новый лейбл:** «стоимость рейса» (поле `logistics_cost` в API, неизменённое имя схемы)

### Примеры
- Груз 10 000 кг при стоимости рейса 5000₽ → 1 рейс → 5000₽
- Груз 25 000 кг при стоимости рейса 5000₽ → 2 рейса → 10 000₽

### Названия документов и форм
- **PDF/XLSX** → заголовок услуги изменен на: **«Услуга по доставке грузов»** (вместо «транспортные расходы»)

## API

### Поле схемы
- **Имя в API:** `logistics_cost` (неизменённое)
- **Описание:** Стоимость одного рейса доставки
- **Тип:** `float` (₽)

**Примечание:** Имя поля в JSON остаётся `logistics_cost`, фронтенд отображает текст «стоимость рейса» через локализацию.
