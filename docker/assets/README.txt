Статические файлы, которые должны попадать в Docker-образ (каталог «банк знаний» в .dockerignore).

ЖБЛСТАРТ.png — плашка (логотип) в шапке коммерческого предложения (PDF/XLSX).

При смене макета замените файл здесь и пересоберите образ:
  docker compose build

Локально по-прежнему используется «банк знаний/ЖБЛСТАРТ.png», если он есть.
Переопределение: COMMERCIAL_OFFER_LOGO_PATH=/path/to/logo.png
