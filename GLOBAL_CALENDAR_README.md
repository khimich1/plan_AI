# Единый календарь производства

## Описание изменений

Реализована функциональность **единого календаря**, который объединяет все производственные планы в одну общую календарную сетку.

### Что изменилось

#### До изменений:
- При нажатии на кнопку «Календарный план» отображались только дни из **активного плана**.
- Если в активном плане было 2 дня, то показывались только 2 кнопки с датами.
- Остальные планы были скрыты от пользователя до переключения активного плана.

#### После изменений:
- При нажатии на кнопку «Календарный план» отображаются **все дни из всех планов**.
- Календарь автоматически определяет диапазон от самой ранней до самой поздней даты.
- На кнопках отображается суммарная загрузка дорожек по всем планам (например, `5/5`).
- При клике на дату показываются дорожки из **всех планов**, которые затрагивают эту дату.

## Технические детали

### 1. Новая функция `get_global_calendar_info()` (plan_manager.py)

**Что делает:**
- Загружает все планы из папки `bot/data/plans/`.
- Определяет самую раннюю и самую позднюю дату среди всех планов.
- Для каждой даты считает общую загрузку дорожек (суммирует занятость по всем планам).
- Определяет статус выполнения (день считается выполненным, если хотя бы в одном плане он отмечен как `completed`).

**Возвращает:**
```python
{
    'start_date': str,          # Самая ранняя дата в формате 'YYYY-MM-DD'
    'total_days': int,          # Количество дней от начала до конца
    'days_info': {              # Информация по каждой дате
        "2026-01-22": {
            "occupied": 3,      # Занято дорожек во всех планах
            "max": 5,           # Максимум дорожек в день
            "completed": False, # Выполнен ли день
            "day_number": 1     # Порядковый номер дня от start_date
        },
        ...
    },
    'completed_days': [1, 2, ...],  # Список номеров выполненных дней
    'plans_count': int,              # Количество планов
    'tracks_count': int              # Суммарное количество дорожек
}
```

### 2. Обновленный обработчик `view_calendar_plan()` (production_calendar.py)

**Что изменилось:**
- Вместо загрузки одного активного плана (`get_active_plan()`) теперь вызывается `get_global_calendar_info()`.
- В сообщении статистики указывается количество планов и общая информация по всем планам.
- Флаг `is_global_calendar=True` сохраняется в `state` для корректной обработки кликов на даты.

**Пример сообщения:**
```
📅 Календарный план производства

📊 Статистика (все планы):
  • Планов: 2
  • Всего дней: 8
  • Выполнено: 0 ✅
  • Осталось: 8
  • Всего дорожек: 21

Выберите день для просмотра документов:
(Формат: дата занято/максимум)
```

### 3. Работа с днями (production_day_view.py)

**Без изменений**, так как обработчик уже использовал функцию `get_tracks_for_date_from_all_plans()`, которая собирает дорожки из всех планов на конкретную дату.

При клике на дату:
- Вычисляется дата выбранного дня на основе `start_date` и `day_number`.
- Загружаются дорожки из **всех планов**, у которых есть эта дата.
- Если дорожки найдены в нескольких планах, показывается детализация по планам.

**Пример сообщения:**
```
📋 День 3 (27.01):
• Дорожки: 1-3
• Количество: 3 дорожек (из 2 планов)

📋 Дорожки из планов:
  • План с 25.01.2026: 2 дор.
  • План с 26.01.2026: 1 дор.
```

## Как использовать

### Для пользователя:

1. Нажмите на кнопку **«Календарный план»** в главном меню планирования.
2. Вы увидите календарь со **всеми днями из всех ваших планов**.
3. Нажмите на любую дату, чтобы увидеть дорожки на этот день.
4. Если на выбранную дату есть дорожки из нескольких планов, бот покажет детализацию.

### Примеры:

#### Пример 1: У вас 2 плана
- **План 1**: с 25.01 по 28.01 (4 дня, 8 дорожек)
- **План 2**: с 25.01 по 26.01 (2 дня, 5 дорожек)

**Результат в календаре:**
- Отображаются дни с **25.01 по 28.01** (всего 4 дня).
- На кнопке **25.01** показано `5/5` (5 дорожек занято из 5 максимум).
- На кнопке **26.01** показано `5/5`.
- На кнопке **27.01** показано `2/5`.
- На кнопке **28.01** показано `2/5`.

#### Пример 2: Клик на дату 25.01
Бот покажет:
```
📋 День 1 (25.01):
• Дорожки: 1-5
• Количество: 5 дорожек (из 2 планов)

📋 Дорожки из планов:
  • План с 25.01.2026 (8д, 16 дор.): 2 дор.
  • План с 25.01.2026 (2д, 5 дор.): 3 дор.
```
