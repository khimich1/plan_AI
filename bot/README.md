# Telegram бот для расчёта и визуализации дорожек ПБ

Эта папка содержит все файлы, связанные с Telegram ботом.

## Структура

- `bot_main.py` - Точка входа бота (запуск aiogram)
- `bot_handlers.py` - Обработчики команд и сообщений
- `bot_config.py` - Конфигурация бота (токен, пути к данным)
- `__init__.py` - Пакет Python для импорта модулей

**Конфигурация:** Файл `.env` находится в корне проекта (на уровень выше)

## Запуск

### Вариант 1: Bash скрипт (рекомендуется) 🚀
```bash
./start_bot.sh
```
Автоматически настроит окружение, установит зависимости и запустит бота с логированием.

### Вариант 2: Из корня проекта
```bash
python run_bot.py
```

### Вариант 3: Напрямую
```bash
python bot/bot_main.py
```

📖 **Подробная инструкция:** См. файл `ЗАПУСК_БОТА.md` в корне проекта

## Настройка

1. **Токен бота:** Отредактируйте файл `.env` в корне проекта:
```bash
BOT_TOKEN=ваш_токен_от_BotFather
```
(Токен можно получить у [@BotFather](https://t.me/BotFather) в Telegram)

2. **Зависимости:** Убедитесь, что все зависимости установлены:
```bash
pip install -r requirements.txt
```

3. **База данных:** Убедитесь, что файл `pb.db` существует в корне проекта

## Функции бота

- `/start` - Главное меню
- `/build_plan` - Построить план дорожки
- `/optimize` - Оптимизация раскроя
- `/help` - Справка
- `/stats` - Статистика проекта
- `/commercial_offer` - Генерация КП в PDF

## Взаимосвязи

Бот использует модули из корня проекта:
- `visualization.py` - Визуализация раскладки
- `optimization.py` - Оптимизация раскроя
- `config_and_data.py` - Конфигурация и данные
- `commercial_offer.py` - Генерация КП
- `price_db.py` - Работа с базой данных цен

Все пути к данным (база, папки результатов) настраиваются в `bot_config.py` относительно корня проекта.
