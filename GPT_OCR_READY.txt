📋 Быстрый старт (3 шага):

   1. Установи библиотеку:
      
      pip install openai

   2. Получи API ключ:
      
      • Зайди на https://platform.openai.com/api-keys
      • Создай ключ (начинается с sk-...)
      • Пополни баланс $5 (хватит на ~2500 фото)

   3. Добавь ключ в bot/bot.env:
      
      OPENAI_API_KEY=sk-твой_ключ_здесь

   4. Запусти бота:
      
      python run_bot.py

❓ Частые вопросы:

   Q: Можно ли использовать без GPT?
   A: Да! Просто не добавляй OPENAI_API_KEY — будет работать EasyOCR.

   Q: Безопасно ли отправлять фото в OpenAI?
   A: OpenAI не хранит изображения. Но если нужна конфиденциальность —
      используй только EasyOCR (работает локально).

   Q: Что если закончатся деньги на балансе?
   A: Бот автоматически переключится на EasyOCR.
