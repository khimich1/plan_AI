# Модуль factory_cost - Сводка реализации

## ✅ Что сделано

### 1. Архитектура модуля (полностью изолирован)

```
factory_cost/
├── __init__.py              # API экспорт
├── db_schema.py             # Схема БД (2 таблицы)
├── excel_reader.py          # Чтение Excel
├── import_from_xlsx.py      # Импорт в БД
├── cost_engine.py           # API получения себестоимости
└── README.md               # Документация
```

### 2. База данных SQLite

**Таблица `factory_plate_costs`:**
- `plate_name, length_dm, width_dm, load_code` (PRIMARY KEY)
- `direct_cost, overhead_cost, full_cost, kef, full_cost_with_kef`
- `volume_m3, concrete_grade, quality_flag`
- `source_file, source_sheet, source_row, updated_at`

**Таблица `factory_plate_cost_components`:**
- `plate_name, component` (PRIMARY KEY)
- `value` (стоимость компонента)
- Компоненты: reinforcement, concrete, loops, izoform

### 3. Скрипты

**`scripts/import_factory_costs.py`:**
- Импорт из Excel в БД
- Поддержка флагов: `--file`, `--no-clear`, `--db`
- Статистика импорта

**`scripts/validate_factory_costs.py`:**
- Проверка сумм компонентов
- Проверка адекватности значений
- Поиск дубликатов
- Поиск плит без компонентов

**`tests/test_factory_cost.py`:**
- Тесты схемы БД
- Тесты чтения Excel
- Тесты импорта
- Тесты API
- Тесты интеграции с парсером

### 4. API

```python
from factory_cost import get_cost_by_plate_name, get_cost_by_params

# По названию
cost = get_cost_by_plate_name("Плиты ПБ 71-12-10п")

# По параметрам (нагрузка определяется автоматически!)
cost = get_cost_by_params(7.1, 1.2)

# Детальная разбивка
from factory_cost.cost_engine import get_cost_breakdown

```

## 🎯 Ключевые особенности

### ✅ ЧТО СДЕЛАНО ПРАВИЛЬНО

1. **Полная изоляция от КП:**
   - Отдельные таблицы БД
   - Не трогает `prices`
   - Не считает маржу/цену продажи

2. **Использование существующего парсера:**
   - НЕ дублирует логику
   - Импортирует функции из `core.config_and_data`
   - Нагрузка 12.5п сохраняется как float

3. **Правильная работа с размерами:**
   - В БД: `length_dm=71, width_dm=12` (дециметры)
   - Названия через `make_plate_name()`: "Плиты ПБ 71-12-8п"
   - Автоопределение нагрузки через `get_load_code_for_plate()`

4. **Профессиональная структура:**
   - Type hints везде
   - Идемпотентные операции
   - Логирование проблем
   - Валидации с флагами

5. **Удобное API:**
   - Поиск по названию
   - Поиск по параметрам (auto load_code)
   - Детальная разбивка
   - Список всех плит

## 🔍 Известные особенности

### Расхождения компонентов (это нормально)

**Все** 351 плита имеют `quality_flag = 'components_mismatch'`

**Почему:** В Excel есть дополнительные статьи затрат помимо:
- Армирование
- Бетон
- Петли
- Изоформ

Расхождение показывает стоимость прочих затрат (транспорт, энергия, зарплата и т.п.)

### КЭФ не найден в Excel

Модуль использует КЭФ = 1.0 (без накладных) по умолчанию.

Если в листе "Себестоимость" будет ячейка с текстом "КЭФ" и числом рядом, оно будет подхвачено автоматически.

### Нагрузка 10п не найдена

В импортированном Excel только плиты с нагрузками 8п и 12.5п.

Если нужны плиты 10п, они должны быть в исходном Excel файле.
