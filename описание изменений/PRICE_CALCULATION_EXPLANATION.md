# 📊 Расчет цены для плит в заказе

## Формат наименования: "ПБ 36-3-8п 4 шт"

### Расшифровка:
- **36** = длина в дециметрах = **3.6 метра**
- **3** = ширина в дециметрах = **0.3 метра (300 мм)**
- **8п** = класс нагрузки **800 кг/м²**
- **4 шт** = количество плит

---

## 🔢 Алгоритм расчета цены

Расчет происходит в функции `build_component_breakdown()` в файле `viz_modules/procurement.py`.

### Шаг 1: Получение базовой цены за плиту шириной 1.2м

```python
# Определяем код нагрузки
load_code = 6 if width_m < 1.0 else 8  # Для 0.3м → load_code = 6

# Получаем цену из базы данных для плиты длиной 3.6м и шириной 1.2м
base_price_1_2m = get_price(3.6, 6, db_path)
# Например: 11 733,00 руб
```

**Источник:** База данных `pb.db` → таблица `prices` → поиск по `length_dm=36` и `load_code=6`

---

### Шаг 2: Расчет базовой цены с учетом ширины

```python
# Коэффициент пропорциональности
width_factor = width_m / 1.2
# width_factor = 0.3 / 1.2 = 0.25

# Базовая цена для плиты шириной 0.3м
base_price = base_price_1_2m * width_factor
# base_price = 11 733,00 × 0.25 = 2 933,25 руб
```

**Формула:** `Базовая цена (0,3м) = Цена за 1.2м × (0,3 / 1.2)`

---

### Шаг 3: Расчет стоимости продольного реза

```python
# Если ширина < 1.15м, значит был продольный рез
long_cuts = 1 if width_m < 1.15 else 0  # Для 0.3м → long_cuts = 1

# Стоимость реза = цена за метр × длина
long_cut_cost = long_cuts * (LONG_CUT_PRICE_PER_M * length)
# long_cut_cost = 1 × (460 × 3.6) = 1 656,00 руб
```

**Константа:** `LONG_CUT_PRICE_PER_M = 460.0 руб/пог.м`

**Примечание:** Если используется каскадная оптимизация, количество резов может быть пересчитано из `OPT_CASCADING_PLAN` (первичные + вторичные резы).

---

### Шаг 4: Расчет стоимости отходов (если есть)

```python
# Если есть отходы из вторичных резов
if waste_width_mm > 0:
    waste_cost = (waste_width_mm / 1200.0) * base_price_1_2m / qty
    # Например: (240 / 1200) × 11 733,00 / 4 = 586,65 руб
```

**Формула:** `Отходы = (ширина_отходов / 1200) × цена_за_1.2м / количество_плит`

---

### Шаг 5: Итого за 1 плиту

```python
total_per_unit = base_price + long_cut_cost + trans_cut_cost + rest_cost + waste_cost
# total_per_unit = 2 933,25 + 1 656,00 + 0 + 0 + 586,65 = 5 175,90 руб
```

**Округление:** до 2 знаков после запятой → `5 175,90 руб`

---

### Шаг 6: Итого за N плит

```python
total_for_qty = total_rounded * qty
# total_for_qty = 5 175,90 × 4 = 20 703,60 руб
```

## 🔍 Где хранятся цены?

1. **База данных:** `pb.db` → таблица `prices`
   - Колонки: `length_dm`, `load_code`, `price`
   - Пример: `length_dm=36, load_code=6, price=11733.00`

2. **Excel файл:** `банк знаний/Новые цены для прайса с 19.08.24.xlsx`
   - Импортируется в базу данных через функцию `import_from_xlsx()`

3. **Константы резов:**
   - `LONG_CUT_PRICE_PER_M = 460.0 руб/пог.м` (в `core/config_and_data.py`)
   - `TRANSVERSE_CUT_PRICE = 1200.0 руб/шт` (в `core/config_and_data.py`)

---

## 📝 Примечания

1. **Класс нагрузки:**
   - Для ширины < 1.0м → `load_code = 6` (600 кг/м²)
   - Для ширины ≥ 1.0м → `load_code = 8` (800 кг/м²)

2. **Каскадная оптимизация:**
   - Если используется `OPT_CASCADING_PLAN`, количество резов пересчитывается с учетом первичных и вторичных резов
   - Формула: `long_cuts = total_cuts_for_this_size / total_plates_from_cuts`

3. **Остатки и отходы:**
   - Остатки (например, 880мм) учитываются как 0, если использованы во вторичных резах
   - Отходы (например, 240мм) распределяются пропорционально количеству плит
