# 🤖 Telegram-бот для расчёта и визуализации плит перекрытия

Автоматизированная система для создания коммерческих предложений, расчёта стоимости и оптимизации раскроя плит перекрытия ПБ.

## 📋 Описание

Бот позволяет:
- 📝 Создавать коммерческие предложения (PDF/Excel)
- 📊 Автоматически рассчитывать стоимость материалов
- 🎯 Оптимизировать раскрой плит для минимизации отходов
- 📷 Распознавать плиты с фотографий (OCR)
- 📈 Генерировать визуализацию раскладки и ведомости
- 💾 Хранить историю заказов в базе данных

## 🔧 Требования

- **Python:** 3.10 или выше
- **Операционная система:** Windows 10/11, Linux, macOS
- **Токен бота:** Получите у [@BotFather](https://t.me/BotFather) в Telegram

## 🚀 Быстрый старт

### 1. Клонирование репозитория

```bash
git clone <URL_вашего_репозитория>
cd Шишов
```

### 2. Создание виртуального окружения

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Linux/macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка переменных окружения

Создайте файл `.env` в корне проекта:

```env
# Токен Telegram бота (получите у @BotFather)
BOT_TOKEN=your_bot_token_here
```

**Как получить токен:**
1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям (придумайте имя и username для бота)
4. Скопируйте полученный токен
5. Вставьте его в файл `.env`

### 5. Запуск бота

```bash
python run_bot.py
```

Если всё настроено правильно, вы увидите:
```
INFO - 🚀 Бот запущен!
```

## 📝 Формат заказа

Бот понимает несколько форматов ввода плит:

**Формат 1:** Обозначение ПБ (рекомендуется)
```
ПБ 78-12-8п 5 шт
ПБ 66,2-12-8п 6
Плиты ПБ 54-10-10п 3
```

**Формат 2:** Размеры через знак умножения
```
1.2×3.39 — 2 шт
0,32x6,63 - 4
```

**Пример полного заказа:**
```
ПБ 78-12-8п 5 шт
ПБ 66,2-12-8п 6
ПБ 54-10-10п 3
0,32x6,63 - 4
```

## 🔍 Частые проблемы

### Бот не запускается

**Ошибка:** `Token is invalid`
- **Решение:** Проверьте токен в файле `.env`. Токен должен быть вида `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`

**Ошибка:** `База данных не найдена`
- **Решение:** Это нормально при первом запуске. База создастся автоматически при первом использовании.

### Бот не распознаёт заказ

- Проверьте формат ввода (см. раздел "Формат заказа")
- Убедитесь, что размеры указаны в правильных единицах (дециметры для ПБ)
- Используйте точку или запятую для дробных чисел

### Ошибка при генерации файлов

**Ошибка:** `Прайс-лист не найден`
- **Решение:** Убедитесь, что в папке `банк знаний/` есть файл с прайсом
- Проверьте путь в `core/config_and_data.py`
