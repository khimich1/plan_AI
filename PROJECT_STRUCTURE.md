## ⚠️ Лишние файлы (можно удалить)

### 1. Временные файлы Excel (`~$*.xlsx`)
**Файлы:**
- `~$!КЗ ПФ Шаблон с чек-листом.xlsx`
- `~$Plan-proizvodstva-PB.xlsx`
- `~$ПЛАН_РАСКЛАДКА_ДОРОЖКА_МАТРИЦА.xlsx`
- `~$раскладка_дорожки_армирование.xlsx`
- `банк знаний/~$Новые цены для прайса с 19.08.24.xlsx`

**Статус:** ⚠️ Временные файлы Excel (создаются автоматически при открытии файлов)  
**Рекомендация:** Можно удалить, но они появятся снова при открытии Excel файлов. Лучше добавить в `.gitignore`.

### 2. Ярлыки Windows
**Файлы:**
- `PDF_Схемы — ярлык.lnk`

**Статус:** ❌ Ярлык Windows, не нужен в проекте  
**Рекомендация:** Удалить

### 3. Пустая папка `db/`
**Содержимое:** Только `__pycache__/`

**Статус:** ⚠️ Папка не используется (база данных `pb.db` в корне)  
**Рекомендация:** Можно удалить, если не планируется использовать

### 4. Результаты работы в корне (опционально)
**Файлы:**
- `Оптимизированный_план_плит_с_остатками.xlsx`
- `План_производства_плит_по_дням.xlsx`
- `Примеры_разрезов_и_остатков.xlsx`
- `Раскладка_плит_СТАТИСТИКА_20251012.png`

**Статус:** ⚠️ Результаты работы  
**Рекомендация:** Можно переместить в `Визуализация_Раскладки/` или оставить как примеры

### 5. Служебные файлы
**Файлы:**
- `промт.txt` - промпт для AI (можно оставить или переместить в документацию)
- `__pycache__/` - кэш Python (добавить в `.gitignore`)

## ✅ Рекомендации по очистке

1. **Создать `.gitignore`** для исключения временных файлов:
   ```
   __pycache__/
   *.pyc
   *.pyo
   ~$*.xlsx
   *.lnk
   .env
   bot.env
   ```

2. **Удалить ярлык:** `PDF_Схемы — ярлык.lnk`

3. **Удалить пустую папку:** `db/` (если не используется)

4. **Опционально:** Переместить результаты работы в `Визуализация_Раскладки/`
