## Что было исправлено

Функция `calculate_plate_cost()` теперь правильно рассчитывает полную себестоимость плиты с учётом **КЭФ** (коэффициента накладных расходов) согласно формулам из Excel.

## Изменённые файлы

1. **cost_calculation/db.py**
   - Добавлена константа `kef = 1.25` в таблицу `cost_constants`
   - Создана функция `get_kef()` для получения КЭФ из БД

2. **cost_calculation/calculation.py**
   - Импортирована функция `get_kef`
   - Изменён расчёт в `calculate_plate_cost()`: теперь считаются прямые затраты, затем применяется КЭФ
   - Добавлены новые поля в результат:
     - `direct_cost` - прямые затраты
     - `overhead_cost` - накладные расходы
     - `full_cost_with_kef` - полная себестоимость с КЭФ
     - `kef` - значение коэффициента

3. **cost_calculation/__init__.py**
   - Экспортирована функция `get_kef` для внешнего использования

## Формула расчёта (по Excel)

```
Прямые затраты = Бетон + Армирование + Петли + Изоформ
Накладные = Прямые затраты × (КЭФ - 1)
Полная себестоимость = Прямые затраты × КЭФ
```

Соответствие листам Excel:
- Лист "Стоимость" → `direct_cost` (прямые затраты)
- Лист "Себестоимость" → `full_cost_with_kef` (с КЭФ)
- Лист "Прайс" → цена = себестоимость × 1.2

## Пример использования

```python
from cost_calculation import calculate_plate_cost, init_default_constants

# Инициализация констант (включая КЭФ = 1.25)
init_default_constants()

# Расчёт себестоимости
result = calculate_plate_cost("ПБ 17-12-6")

print(f"Прямые затраты: {result['direct_cost']:.2f} руб")
print(f"КЭФ: {result['kef']}")
print(f"Накладные: {result['overhead_cost']:.2f} руб")
print(f"Полная себестоимость: {result['full_cost_with_kef']:.2f} руб")
```

## Обратная совместимость

Поле `total_cost` сохранено для обратной совместимости и содержит значение прямых затрат. Для получения полной себестоимости используйте `full_cost_with_kef`.

## Изменение КЭФ

Чтобы изменить значение КЭФ, отредактируйте константу в БД:

```python
from cost_calculation import get_constant
import sqlite3

conn = sqlite3.connect('pb.db')
cur = conn.cursor()
cur.execute("UPDATE cost_constants SET value = ? WHERE key = 'kef'", (1.3,))
conn.commit()
conn.close()
```

Или измените значение в `cost_calculation/db.py` (строка 118) и переинициализируйте:

```python
from cost_calculation import init_default_constants
init_default_constants()
```
